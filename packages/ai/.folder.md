# ai

## 地位

Tessera 的模型供应商目录、AI SDK 运行时适配、模型发现服务与可复用 AI 产品界面。

## 逻辑

领域入口公开供应商和配置契约，`server/` 组合供应商配置持久化领域服务、内置 Skill instructions、原生 AI SDK adapter 与公共/鉴权模型目录请求，`react/` 使用 `@lobehub/icons` 并通过注入的窄函数组合设置界面；包不反向依赖桌面应用。

## 约束

- 包不得依赖 `apps/`，桌面端只能通过公开子路径使用 AI 能力。
- API Key 不进入渲染层持久化存储；新输入只短暂存在于表单内存，落盘前必须由主进程安全存储加密。
- 供应商原生差异由适配器保留，不在界面层伪装成完全相同的协议。
- 模型目录请求不使用生成调用，也不要求用户维护独立 models URL。

## 成员清单

- `src/`：供应商目录、模型发现、AI SDK 运行时、测试与 React 设置界面。
- `package.json`：领域、React、server 公开入口，以及 Skill、AI SDK provider、LobeHub 图标和测试依赖。
- `tsconfig.json`：领域与 React 源码的类型检查配置。

## 触发器

供应商范围、适配边界、公开入口、依赖方向或成员变化时更新本文。
