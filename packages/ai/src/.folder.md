# ai/src

## 地位

AI 包的领域入口和实现源码。

## 逻辑

`provider-catalog.ts` 提供无副作用供应商与配置模型，根入口只导出不依赖 React 的领域 API，`react/` 作为独立公开子路径消费这些 API。

## 约束

- 根入口保持与 UI 框架无关，供主进程和测试安全复用。
- 默认端点必须有回归测试，模型发现路径由未来适配器内部推导。

## 成员清单

- `index.ts`：AI 领域公开入口。
- `provider-catalog.ts`：供应商元数据、配置草稿和纯状态转换。
- `provider-catalog.test.ts`：供应商范围、默认端点、搜索与模型草稿测试。
- `react/`：品牌资源与 AI 设置界面公开入口。

## 触发器

领域文件、公开导出、供应商配置或目录职责变化时更新本文。
