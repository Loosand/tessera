# ai/src

## 地位

AI 包的领域入口与公开子路径索引；根层只保留稳定入口和职责目录。

## 逻辑

`catalog/` 归一化供应商、连接和模型事实，`routing/` 根据模型事实与请求意图收敛执行端点和逐轮策略；`server/` 在受信任主进程执行网络与 Agent 运行时，`react/` 向渲染层提供配置界面和会话适配，根入口聚合无 UI、无服务端副作用的领域 API。

## 约束

- 根入口保持与 UI 框架和服务端运行时无关。
- `server/` 不得被渲染层直接导入。
- 目录内部实现通过根入口或明确公开子路径供包外消费。
- 新领域文件先归入 `catalog/` 或 `routing/`，形成独立边界后再新增目录与 `.folder.md`。

## 成员清单

- `index.ts`：AI 领域稳定公开入口。
- `catalog/`：供应商目录、连接草稿、模型能力与输入规范化。
- `routing/`：意图推断、模型执行路由与逐轮 RunPolicy。
- `react/`：AI 设置、模型界面与 Electron 会话适配公开子路径。
- `server/`：配置、网络、AI SDK 与 ToolLoopAgent 运行时公开子路径。

## 触发器

领域边界、公开导出、目录职责或成员变化时更新本文。
