# ai/src

## 地位

AI 包的领域入口和实现源码。

## 逻辑

`provider-catalog.ts` 提供无副作用供应商、持久化配置水合、公共目录能力与配置模型，`model-capabilities.ts` 合并远端与内置能力事实，根入口只导出领域 API；`server/` 承担配置验证/密钥存储抽象、受信任网络与 AI SDK 运行时，`react/` 通过独立公开子路径消费领域 API、LobeHub 图标和调用方注入的窄配置函数。

## 约束

- 根入口保持与 UI 框架无关，供主进程和测试安全复用。
- 默认端点、模型目录推导、鉴权差异和错误脱敏必须有回归测试。
- server 子路径不得被渲染层直接导入。

## 成员清单

- `index.ts`：AI 领域公开入口。
- `model-capabilities.ts`：保守归一化模型的视觉、推理、搜索和工具能力及其来源。
- `provider-catalog.ts`：供应商元数据、配置草稿和纯状态转换。
- `provider-catalog.test.ts`：供应商范围、默认端点、公共目录能力、搜索与模型草稿测试。
- `react/`：LobeHub 供应商/模型图标与 AI 设置界面公开入口。
- `server/`：配置持久化领域服务、模型目录网络适配、AI SDK provider 工厂和回归测试。

## 触发器

领域文件、公开导出、供应商配置或目录职责变化时更新本文。
