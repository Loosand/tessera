# ai/src/react

## 地位

基于 AI 领域目录和 Tessera 设计系统的可复用 React 界面层。

## 逻辑

`@lobehub/icons` 的 `ProviderIcon` 与 `ModelIcon` 按需加载，分别按供应商键和完整模型 ID 解析品牌，未知模型回退到默认头像；统一模型头像可在设置与任务输入之间复用。设置界面由桌面端注入类型化配置读写/删除和模型发现函数，启动时水合持久化草稿，模型同步、增删与启停成功后立即保存；`use-electron-chat.ts` 通过窄桥把 AI SDK React 状态机映射到主进程流式事件。

## 约束

- 只使用 `@tessera/design-system` 暴露的交互原语。
- 不直接访问 Electron、文件系统、数据库或浏览器持久化存储。
- 新输入的明文密钥只允许短暂存在于组件内存；持久化后组件只接收 `apiKeyConfigured`，网络调用由桌面端注入的类型化 IPC 函数完成。
- 模型图标必须从完整模型 ID 推导且保留未知模型回退，不维护易过期的本地品牌 SVG 副本。
- 完整图标映射必须拆分为异步 chunk，不能进入工作区首屏 bundle。

## 成员清单

- `index.ts`：React 子路径公开入口。
- `ai-model-icon.tsx`：按完整模型 ID 异步解析并统一呈现模型头像。
- `ai-settings.tsx`：与连接配置解耦的 AI 可用性和工具建议权限界面。
- `ai-provider-settings.tsx`：按需加载供应商/模型图标，水合并保存/删除持久化配置，提供全部供应商总览、常驻详情、连接测试和操作后即时持久化的分组模型目录。
- `use-electron-chat.ts`：AI SDK React `useChat` 到 Electron 对话 IPC/事件流的可独立验证 Transport 封装。
- `use-electron-chat.test.ts`：合成完整增量序列并验证 AI SDK React 消息消费者逐段收到正文。

## 触发器

React 公开组件、品牌资源、交互状态或成员变化时更新本文。
