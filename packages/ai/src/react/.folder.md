# ai/src/react

## 地位

基于 AI 领域目录和 Tessera 设计系统的可复用 React 界面层。

## 逻辑

品牌资源映射到供应商定义，设置界面维护会话内草稿并通过公开入口供桌面应用组合。

## 约束

- 只使用 `@tessera/design-system` 暴露的交互原语。
- 不直接访问 Electron、文件系统、数据库或浏览器持久化存储。
- 密钥只允许存在于组件内存，接入安全存储后改走类型化 IPC。

## 成员清单

- `index.ts`：React 子路径公开入口。
- `ai-provider-settings.tsx`：AI 可用性、供应商总览和详情配置界面。
- `assets.d.ts`：品牌 SVG 静态资源类型声明。

## 触发器

React 公开组件、品牌资源、交互状态或成员变化时更新本文。
