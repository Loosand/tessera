# ai/src/catalog

## 地位

AI 供应商连接目录与模型事实的纯领域层。

## 逻辑

供应商目录先定义协议、端点和连接草稿，模型能力模块合并内置、远端与用户覆盖事实，输入规范化模块为配置、目录发现和运行时提供共同边界。

## 约束

- 保持无网络、无存储和无 UI 副作用。
- 默认目录、能力来源优先级、连接身份和输入边界必须有回归测试。
- 不根据界面状态推断运行期可用性，实际路由由 `../routing/` 完成。

## 成员清单

- `provider-catalog.ts`、`provider-catalog.test.ts`：供应商/端点目录、连接草稿转换及回归测试。
- `provider-catalog.type-test.ts`：供应商与动态连接身份的编译期契约。
- `model-capabilities.ts`、`model-capabilities.test.ts`：模型能力、模态、Token 与端点绑定事实及测试。
- `provider-input-validation.ts`：API 根地址和模型 ID 的共同规范化边界。

## 触发器

供应商目录、模型事实、输入规范化或成员变化时更新本文。
