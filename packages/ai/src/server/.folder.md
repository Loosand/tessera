# ai/src/server

## 地位

AI 包中仅供受信任主进程使用的网络与 AI SDK 运行时边界。

## 逻辑

`provider-config-service.ts` 通过依赖注入的配置仓储与安全存储完成协议/连接校验、旧模型能力迁移、统一模型事实持久化、加密密钥解析和公开配置隔离；`model-discovery.ts` 根据协议推导可选模型目录，公共目录省略凭据、受保护目录设置鉴权并归一化响应，404/405 作为目录不受支持而非连接失败；`ai-sdk-runtime.ts` 只执行请求期解析器已明确选择的生成端点，DeepSeek V4 原生联网默认走同时支持 thinking 与 Web Search 的 Anthropic Messages，Responses 保留为端点回退并显式声明推理模型语义，普通请求与研究 Skill 使用不同的有界搜索额度；`task-agent.ts` 再以 AI SDK `callOptionsSchema` / `prepareCall` 消费受信任 RunPolicy，统一收窄工具、推理、预算和内置/主进程复核用户 Skill instructions；显式研究额外读取持久化领域进度，在首次搜索前只允许计划/核心消歧，首次深读后若尚无证据则强制登记，预算收尾时强制完成检查，并在领域完成后固定保留一个无工具最终文本步骤；全部运行从 `onStepEnd` / `onEnd` 原生生命周期归一化完成原因、Token、缓存、步骤/工具计数和性能指标。所有任务共用结构化交互工具、托管内容库领域工具与 `ToolLoopAgent`；有工作区授权时，同一工具循环额外组合受限 Markdown 工具和主进程发现的强制审批 MCP 工具，显式 Markdown 附件在进入模型前转换为带材料边界的文本，持久化历史仍保留可见附件 Part。

## 约束

- API Key 不记录、不写入错误消息；持久化时只允许保存平台安全存储生成的密文，公开配置只返回是否已配置。
- 模型目录地址由 API 根地址推导，界面不得要求用户填写独立 models URL。
- 模型目录请求允许省略 API Key；适配器只在存在密钥时发送鉴权头，是否允许匿名访问由远端服务决定。
- 兼容协议允许多条具名连接，官方供应商保持单例；运行时必须以 `configId` 解析具体凭据。
- 兼容端点返回目录 404/405 时必须允许手动模型 ID，不能据此判定生成接口不可用。
- 只允许 http(s) 端点，禁止 URL 内嵌账号或密码，网络请求必须有超时。
- 供应商原生适配器优先；OpenAI 兼容服务与 OpenRouter 使用 AI SDK compatible adapter。

## 成员清单

- `index.ts`：服务端子路径公开入口。
- `provider-config-service.ts`：协议与连接实例验证、旧模型能力迁移、统一模型事实归一化、仓储/安全存储抽象、加解密与连接凭据解析。
- `provider-config-service.test.ts`：跨实例恢复、旧配置迁移、兼容协议多连接、官方单例、密钥隔离、保留/移除和删除配置测试。
- `model-discovery.ts`：模型目录 URL、鉴权、请求、归一化和错误脱敏。
- `model-discovery.test.ts`：模型发现协议、鉴权回退与目录不受支持降级的回归测试。
- `ai-sdk-runtime.ts`：五类供应商和显式端点到 AI SDK `LanguageModel` 的映射、搜索额度约束与原生联网工具注册。
- `ai-sdk-runtime.test.ts`：真实 provider factory 映射和有界搜索额度测试。
- `chat-runtime.ts`：统一 Agent 复用的消息输入约束、显式 Markdown 附件材料化、搜索额度、错误归类脱敏及公开增量裁剪；不再提供独立 Chat 运行入口。
- `chat-runtime.test.ts`：验证文档材料边界、工具增量、搜索额度和错误文案只按共享契约公开。
- `agent-runtime.ts`：组合供应商原生搜索、主进程研究领域服务、工作区读写工具、MCP 动态工具、标准人工审批、Agent 指令与资源上限，并裁剪网页正文后实现统一 `AgentRuntime` 端口的 AI SDK 工具循环。
- `agent-runtime.test.ts`：写入工具根对象 JSON Schema、create/update 条件和 MCP 强制人工审批回归测试。
- `task-agent.ts`：通过类型化 call options 动态配置无工作区和工作区任务共用、带研究阶段工具门禁、稳定 Telemetry 标识与 AI SDK 原生生命周期指标归一化的 ToolLoopAgent。
- `task-agent.test.ts`：RunPolicy Schema、conversation/workspace-read/workspace-write 工具收窄、研究计划/预算/完成状态与生命周期指标回归测试。
- `research-tools.ts`：主进程研究服务到计划、网页深读、证据与完成检查工具的窄适配，并从公共消息裁剪网页正文。
- `research-tools.test.ts`：研究工具集合与正文仅进入当前模型上下文、不写入公共消息的回归测试。
- `skill-instructions.ts`：按需加载任务所选内置 Skill，或接收主进程已复核且 ID 匹配的用户 Skill，并装配不提升权限的 AI SDK 共用 instructions。
- `skill-instructions.test.ts`：问答空选择、内置/用户单 Skill 注入、用户正文复核和权限边界回归测试。
- `task-interaction-tools.ts`：Chat/Agent 共用的核心语义消歧暂停工具、每个用户请求一次的暴露限制与 Research Skill 结构化计划工具。
- `task-interaction-tools.test.ts`：单问题/计划 Schema、无执行暂停语义、每请求一次限制和 Skill 工具暴露边界测试。
- `content-domain-tools.ts`：主进程混合内容服务到 AI SDK 项目/Artifact 查询、创建、检查与安全移动工具的窄适配，并为所有写入启用标准审批。
- `content-domain-tools.test.ts`：领域输入不接受路径、只读查询直接执行和写操作强制审批测试。
- `../intent-routing.ts`：自动模式下只对明确的研究/写作请求收窄内置 Skill，显式选择始终优先，普通问答和项目操作保持自动。

## 触发器

供应商协议、鉴权方式、AI SDK 适配器、服务端导出或成员变化时更新本文。
