# ai/src/server

## 地位

AI 包中仅供受信任主进程使用的网络与 AI SDK 运行时边界。

## 逻辑

`provider-config-service.ts` 通过依赖注入的配置仓储与安全存储完成校验、加密密钥解析和公开配置隔离；`model-discovery.ts` 根据供应商协议推导模型目录，公共目录省略凭据、受保护目录设置鉴权并归一化响应；`ai-sdk-runtime.ts` 将同一连接配置映射到真实 AI SDK `LanguageModel`。

## 约束

- API Key 不记录、不写入错误消息；持久化时只允许保存平台安全存储生成的密文，公开配置只返回是否已配置。
- 模型目录地址由 API 根地址推导，界面不得要求用户填写独立 models URL。
- 模型目录请求允许省略 API Key；适配器只在存在密钥时发送鉴权头，是否允许匿名访问由远端服务决定。
- 只允许 http(s) 端点，禁止 URL 内嵌账号或密码，网络请求必须有超时。
- 供应商原生适配器优先；OpenAI 兼容服务与 OpenRouter 使用 AI SDK compatible adapter。

## 成员清单

- `index.ts`：服务端子路径公开入口。
- `provider-config-service.ts`：配置验证、仓储/安全存储抽象、加解密与连接凭据解析。
- `provider-config-service.test.ts`：跨实例恢复、密钥隔离、保留/移除和删除配置测试。
- `model-discovery.ts`：模型目录 URL、鉴权、请求、归一化和错误脱敏。
- `model-discovery.test.ts`：模型发现协议回归测试。
- `ai-sdk-runtime.ts`：五类供应商到 AI SDK `LanguageModel` 的映射。
- `ai-sdk-runtime.test.ts`：真实 provider factory 映射测试。
- `chat-runtime.ts`：普通对话输入约束、AI SDK 流式生成和公开增量裁剪。

## 触发器

供应商协议、鉴权方式、AI SDK 适配器、服务端导出或成员变化时更新本文。
