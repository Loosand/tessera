# ai/src/server

## 地位

AI 包中仅供受信任主进程使用的网络与 AI SDK 运行时边界。

## 逻辑

`provider-config-service.ts` 通过依赖注入的配置仓储与安全存储完成协议/连接校验、兼容协议多连接、加密密钥解析和公开配置隔离；`model-discovery.ts` 根据协议推导可选模型目录，公共目录省略凭据、受保护目录设置鉴权并归一化响应，404/405 作为目录不受支持而非连接失败；`ai-sdk-runtime.ts` 将具体连接配置映射到真实 AI SDK `LanguageModel`，并在需要原生联网时切换到供应商已验证的生成协议，普通对话与研究 Skill 使用不同的有界搜索额度；DeepSeek 官方 Anthropic 端点的已知 Web Search 错误形状差异在进入 SDK Schema 前由窄响应中间件归一化；当前选中 Skill 的 `SKILL.md` 正文按需加载并通过 AI SDK `instructions` 注入，Chat 和 Agent 共用仅用于核心语义消歧、每个用户请求最多一次的客户端问答工具，Research Skill 额外获得计划工具；Chat 使用受限多步 `streamText`，工作区 Agent 通过统一 `AgentRuntime` 端口运行主进程注入工具的 `ToolLoopAgent`。持久化任务消息在进入 SDK 前使用泛型消息类型和实际工具 Schema 校验，两种运行时共享公开增量裁剪。

## 约束

- API Key 不记录、不写入错误消息；持久化时只允许保存平台安全存储生成的密文，公开配置只返回是否已配置。
- 模型目录地址由 API 根地址推导，界面不得要求用户填写独立 models URL。
- 模型目录请求允许省略 API Key；适配器只在存在密钥时发送鉴权头，是否允许匿名访问由远端服务决定。
- 兼容协议允许多条具名连接，官方供应商保持单例；运行时必须以 `configId` 解析具体凭据。
- 兼容端点返回目录 404/405 时必须允许手动模型 ID，不能据此判定生成接口不可用。
- 只允许 http(s) 端点，禁止 URL 内嵌账号或密码，网络请求必须有超时。
- 供应商原生适配器优先；OpenAI 兼容服务与 OpenRouter 使用 AI SDK compatible adapter。

## 成员清单

- `index.ts`：服务端子路径公开入口。
- `provider-config-service.ts`：协议与连接实例验证、仓储/安全存储抽象、加解密与连接凭据解析。
- `provider-config-service.test.ts`：跨实例恢复、兼容协议多连接、官方单例、密钥隔离、保留/移除和删除配置测试。
- `model-discovery.ts`：模型目录 URL、鉴权、请求、归一化和错误脱敏。
- `model-discovery.test.ts`：模型发现协议、鉴权回退与目录不受支持降级的回归测试。
- `ai-sdk-runtime.ts`：五类供应商到 AI SDK `LanguageModel` 的映射、生成协议切换、搜索额度约束与原生联网工具注册。
- `ai-sdk-runtime.test.ts`：真实 provider factory 映射和有界搜索额度测试。
- `deepseek-anthropic-response.ts`：DeepSeek 官方 Anthropic JSON/SSE Web Search 错误结果的窄协议归一化。
- `deepseek-anthropic-response.test.ts`：错误对象归一化、正常结果不变与跨网络分片流测试。
- `chat-runtime.ts`：通用消息输入约束、普通 Chat 流式生成、按 Skill 分配搜索额度、错误归类脱敏及正文、reasoning、来源、工具公开增量裁剪。
- `chat-runtime.test.ts`：验证工具增量、搜索额度和错误文案只按共享契约公开。
- `agent-runtime.ts`：供应商兼容的工作区读写工具对象 Schema、标准人工审批、Agent 指令、步骤/时间/token 上限，以及实现统一 `AgentRuntime` 端口的 AI SDK 工具循环。
- `agent-runtime.test.ts`：写入工具根对象 JSON Schema 与 create/update 条件校验回归测试。
- `skill-instructions.ts`：按需加载任务所选内置 Skill，并装配不提升权限的 AI SDK 共用 instructions。
- `skill-instructions.test.ts`：问答空选择、单 Skill 注入和权限边界回归测试。
- `task-interaction-tools.ts`：Chat/Agent 共用的核心语义消歧暂停工具、每个用户请求一次的暴露限制与 Research Skill 结构化计划工具。
- `task-interaction-tools.test.ts`：单问题/计划 Schema、无执行暂停语义、每请求一次限制和 Skill 工具暴露边界测试。

## 触发器

供应商协议、鉴权方式、AI SDK 适配器、服务端导出或成员变化时更新本文。
