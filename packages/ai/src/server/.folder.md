# ai/src/server

## 地位

AI 包中仅供受信任主进程使用的供应商适配、轻量 Agent 编排与 AI SDK 运行时边界。

## 逻辑

供应商配置先经 `provider-config-service.ts`、`model-discovery.ts` 和 `ai-sdk-runtime.ts` 解析为当前模型与可选原生
`web_search`；`agent-runtime.ts` 只按本轮 RunPolicy 和实际授权组合简短 instructions、`request-user-input`、无状态
`read-web-source`、工作区 `read/edit/write`、可选受控 `bash` 与 MCP。`task-agent.ts` 复用 AI SDK
`ToolLoopAgent` 负责通用 step/tool 循环；在每个 step 出站前固定 Provider retry、按 Tool Call 源顺序归一并行
结果，并对超预算历史做可审计投影压缩。它不再解释内容库对象或研究阶段状态机。

持久化消息进入模型前由 `chat-runtime.ts` 按当前 active tool set 投影，旧工具审批和已退出工具不会重新进入模型；
`context-compaction.ts` 只缩短下一次模型调用投影，`context-budget.ts` 随后生成不含正文的
ContextManifest 并阻断仍超预算的输入。工具和供应商异常先转为稳定公开错误；供应商响应中的原始错误正文以 16,000
字符为界进入运行诊断，只剔除 API Key / Authorization 凭据。网页正文只存在于当前模型工具结果，公共消息仅保留 URL、标题、哈希和截断元数据。最终正文完成后，
`follow-up-questions.ts` 可执行非关键的结构化引申问题后处理，其失败不改变主回答结果。

Research 与 Writing 是方法型 Skill。Research 可使用供应商 `web_search` 和 `read-web-source` 完成候选发现、深读与
交叉核验，但不再通过模型可见的计划、证据、推荐和完成检查命令维护领域状态。内容库和历史研究数据由主进程/UI
继续读取，不进入新通用 run 的工具集合。

## 约束

- API Key 不记录、不写入错误消息；持久化和出站前必须校验为安全可打印 ASCII。
- 模型目录地址由 API 根地址推导；只允许 http(s)，禁止 URL 内嵌凭据，网络请求必须有超时。
- 兼容协议允许多条具名连接，官方供应商保持单例；运行时必须以 `configId` 解析具体凭据。
- 模型只看见本轮实际启用的工具；Skill 不能提升权限或让不存在的工具变得可用。
- 文件能力由主进程执行边界保证路径、完整读取许可、冲突、串行和提交前版本复核；AI 适配层只说明并传递分页/单行续读协议，不复制执行规则。
- MCP 是独立信任域，当前仍固定逐工具审批；工具输入输出、供应商请求载荷、响应 Header 和堆栈不得进入 renderer，供应商错误响应正文是有界且剔除凭据的唯一原始诊断例外。
- 不平行实现 Agent 循环、工具状态机、UIMessage 转换或 React chat 状态。

## 成员清单

- `api-key-validation.ts`：配置、模型发现与生成共用的 API Key 安全字符校验。
- `provider-config-service.ts` / `.test.ts`：连接验证、旧能力迁移、统一模型事实、安全存储与公开配置隔离。
- `model-discovery.ts` / `.test.ts`：模型目录 URL、鉴权、归一化与目录不支持降级。
- `ai-sdk-runtime.ts` / `.test.ts`：供应商协议到 AI SDK 模型、端点与已验证版本原生联网工具的映射，以及复杂工具续轮 wire shape 回归。
- `chat-runtime.ts` / `.test.ts`：统一消息输入、附件材料化、active-tool 历史投影、搜索额度、错误分类与供应商响应正文凭据剔除。
- `agent-runtime.ts`：组合轻量 instructions、可选 Web、交互、工作区与 MCP 工具，并公开标准 Agent UI 流。
- `agent-runtime.test.ts`：精简提示词、文件/测试/构建请求的工作区相关性、搜索预算续答与 MCP 审批回归。
- `agent-runtime-search-budget.test.ts`：兼容端点搜索额度错误与正文续答回归。
- `task-agent.ts` / `.test.ts`：类型化 RunPolicy、工具 scope、明确 Provider retry、工具源序、ContextManifest 与 AI SDK 生命周期指标。
- `task-interaction-tools.ts` / `.test.ts`：每个用户请求最多一次的核心语义消歧工具。
- `workspace-tools.ts` / `.test.ts`：工作区端口到 `read/edit/write/bash`、分页/单行续读、Bash 读写级别与严格 Schema 的 AI SDK 窄适配。
- `web-tools.ts` / `.test.ts`：无状态 `read-web-source` 适配与公共消息正文裁剪。
- `skill-instructions.ts` / `.test.ts`：内置或已复核用户 Skill 的按需装配与权限边界。
- `context-budget.ts` / `.test.ts`：Token 启发式、ContextManifest 和已知超预算阻断。
- `context-compaction.ts` / `.test.ts`：保留最新 turn 的确定性模型投影压缩、compaction marker 和并行工具结果源序归一。
- `follow-up-questions.ts` / `.test.ts`：回答后的结构化引申问题及非关键指标合并。
- `index.ts`：服务端子路径公开入口。
- `../intent-routing.ts` / `.test.ts`：自动模式下对明确研究/写作请求选择方法型 Skill。

## 触发器

供应商协议、鉴权方式、AI SDK 适配器、Agent 工具集合、服务端导出或成员变化时更新本文。
