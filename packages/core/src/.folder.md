# core/src

## 地位

应用核心包的源码入口。

## 逻辑

当前提供保留字面量类型的产品区域元数据、由目录反向推导的区域联合类型和应用信息工厂，后续领域增长时按职责拆分。

## 约束

- 保持平台无关与可独立测试。
- 对外能力必须从 `index.ts` 明确导出。
- 有限目录优先以 `as const satisfies` 保存事实，再从事实反向推导联合类型。

## 成员清单

- `index.ts`：当前核心类型、产品区域与应用信息工厂。
- `index.type-test.ts`：产品区域联合与应用信息工厂字面量保真的编译期契约。

## 触发器

核心文件增删、重命名或导出职责变化时更新本文。
