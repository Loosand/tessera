# packages

## 地位

存放跨应用复用的领域、运行时与 UI 能力。

## 逻辑

领域契约位于底层，核心与适配器依赖契约，应用在最上层组合公开 API。

## 约束

- 包只通过公开导出互相依赖。
- 包不得反向依赖 `apps/`。
- 只有出现真实运行时、安全或测试边界时才新增包。

## 成员清单

- `contracts/`：共享 IPC 与领域契约。
- `core/`：应用核心服务。
- `agent-runtime/`：可替换 Agent 运行时边界。
- `database/`：Drizzle + SQLite 本地数据层。
- `skills/`：Skill 发现与加载契约。
- `design-system/`：共享 React 组件与视觉系统。

## 触发器

包增删、依赖方向或包职责变化时更新本文。
