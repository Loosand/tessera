# skills

## 地位

可移植 `SKILL.md` 工作流的发现与加载契约包。

## 逻辑

描述 Skill 的来源、作用域和所需权限；内置注册表常驻展示元数据，并在选中后动态读取、校验 `SKILL.md` 正文。

## 约束

- Skill 声明不等同于权限批准。
- 本包不执行外部命令或直接读取工作区。
- 模型上下文只接收当前选中 Skill 的正文，未选中 Skill 只暴露元数据。

## 成员清单

- `src/`：Skill 领域契约。
- `builtins/`：研究与写作两个内置标准 Skill。
- `package.json`：包元数据、依赖与公开入口。
- `tsconfig.json`：类型检查配置。

## 触发器

Skill 模型、内置目录、渐进式加载、权限关系、公共入口或成员变化时更新本文。
