# builtins

## 地位

随 Tessera 发布、可按标准 `SKILL.md` 检查的官方 Skill 根目录。

## 逻辑

每个直接子目录是一份独立 Skill；选择器常驻元数据，模型只在任务选中对应 Skill 时按需加载正文。

## 约束

- 每份 Skill 必须以 `SKILL.md` 为行为事实源，并只在 frontmatter 中声明 `name` 和 `description`。
- `agents/openai.yaml` 只承载产品展示元数据，不进入模型上下文。
- Skill 声明的权限不是批准，实际工具仍受任务模式、权限网关和人工审批约束。

## 成员清单

- `research/`：最小研究工作流。
- `writing/`：最小写作工作流。

## 触发器

内置 Skill 增删、目录约定、加载策略或权限关系变化时更新本文。
