# builtins

## 地位

随 Tessera 发布、可按标准 `SKILL.md` 检查的官方 Skill 根目录。

## 逻辑

每个直接子目录是一份独立 Skill；选择器常驻元数据，模型只在任务选中对应 Skill 时按需加载正文。

## 约束

- 每份 Skill 必须以 `SKILL.md` 为行为事实源，并只在 frontmatter 中声明 `name` 和 `description`。
- `agents/openai.yaml` 只承载产品展示元数据，不进入模型上下文。
- Skill 声明的权限不是授权，实际工具仍受任务模式、资源授权和执行器边界约束；MCP 等外部副作用能力继续使用独立审批策略。

## 成员清单

- `research/`：轻量研究方法，只在无法判断的核心语义歧义时询问一次，并使用可选 `web_search`、无状态 `read-web-source` 与现有材料完成来源评估、深读、交叉核验和限制说明。
- `writing/`：Tessera 写作工作流，区分写作动作与材料性质，主动使用已授权材料补齐关键缺口；遵守一次核心澄清上限，对后续冲突保留分支与限制，在保持事实、作者声音和修改边界的前提下完成起草或修订，并执行四层质检。

## 触发器

内置 Skill 增删、目录约定、加载策略或权限关系变化时更新本文。
