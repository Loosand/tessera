# skills/src

## 地位

Skill 发现与加载契约的源码入口。

## 逻辑

用集中作用域和只读描述符统一表达内置、用户级、工作区级 Skill 及其声明资源权限；内置注册表不加载指令正文，只有研究或写作被显式选择后才动态读取并严格校验标准 `SKILL.md`，自动与问答创作方式不伪造 Skill 正文。

## 约束

- 文件名常量与 `SKILL.md` 协议保持一致。
- 权限效果复用 `agent-runtime` 的共享类型。
- 作用域只能来自 `SKILL_SCOPES`，具体 Skill 优先通过 `defineSkill` 声明。
- frontmatter 只接受标准 `name` 和 `description`；Skill 正文不进入常驻目录。

## 成员清单

- `index.ts`：Skill 文件名、集中作用域、描述符、定义器、严格解析器和内置渐进式加载注册表。
- `index.type-test.ts`：Skill 名称、作用域和权限动作字面量保真的编译期契约。
- `index.test.ts`：frontmatter 校验、元数据常驻和正文按需加载回归测试。
- `raw.d.ts`：构建器按原文加载 `SKILL.md` 的类型声明。

## 触发器

契约文件增删、Skill 作用域或权限结构变化时更新本文。
