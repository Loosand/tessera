# contracts/src/tasks

## 地位

任务执行策略、Skill/网络字面量与上下文资源摘要契约目录。

## 逻辑

任务运行策略把创作方式、Skill、联网与工具作用域冻结为跨进程结构；ContextManifest、压缩 marker 和资源摘要只携带脱敏预算与能力事实，运行时守卫在 IPC 和持久化恢复边界拒绝非法载荷。

## 约束

- 契约不依赖具体 Agent、供应商或桌面运行时实现。
- 资源摘要不得包含正文、秘密或绝对路径。
- 字面量、资源限制与守卫必须由根入口测试覆盖。

## 成员清单

- `task-run-policy.ts`：TaskSkill、网络模式、RunPolicy、ContextManifest、压缩 marker、资源摘要及守卫。

## 触发器

任务执行策略、资源摘要、运行时守卫或成员变化时更新本文。
