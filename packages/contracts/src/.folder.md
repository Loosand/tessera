# contracts/src

## 地位

共享跨进程契约的稳定入口与领域目录索引。

## 逻辑

`index.ts` 保持 `@tessera/contracts` 的唯一公开入口并聚合 IPC、窗口生命周期、AI/MCP/Skill、内容、消息与桌面 API 契约；任务执行策略、压缩 marker 与 ContextManifest 下沉到 `tasks/`，根入口聚合带 Progress、Execution Context、turn/tool/terminal 和有界供应商错误正文的运行解释，调用方导入路径保持稳定。

## 约束

- 类型可被 Electron、浏览器和 Node.js 共同引用，不导入具体运行时实现。
- IPC 调用签名只在 `DesktopApiContract` 定义一次。
- 跨进程未知载荷使用 `unknown`，不得退化为 `any`。
- 包外只通过根入口消费契约，领域目录不新增公开子路径。

## 成员清单

- `index.ts`：聚合并重新导出全部稳定公开契约。
- `index.test.ts`：根入口运行时守卫与供应商错误正文长度边界回归测试。
- `index.type-test.ts`：根入口类型等价和桌面 API 关联测试。
- `tasks/`：逐轮任务执行策略、资源摘要与运行时守卫。

## 触发器

契约领域、根导出、IPC 签名或成员变化时更新本文。
