# contracts/src

## 地位

共享契约包的源码入口。

## 逻辑

`index.ts` 保持唯一公开入口并聚合 IPC 频道、窗口生命周期、AI/MCP/用户 Skill、研究、内容对象、消息与桌面 API 等跨进程契约；`task-run-policy.ts` 独立维护逐轮运行策略、Skill/网络字面量及资源摘要守卫。根入口只重新导出领域文件，调用方无需改变导入路径。桌面桥接继续由泛型方法契约统一关联调用方式、频道、参数元组和返回值。

## 约束

- 类型应可在 Electron、浏览器和 Node.js 环境共同引用。
- 不导入具体运行时实现。
- IPC 调用签名只在 `DesktopApiContract` 定义一次，`DesktopApi` 与查询辅助类型必须由它推导。
- 跨进程未知载荷使用 `unknown`，不得为了方便退化为 `any`。

## 成员清单

- `index.ts`：聚合并重新导出所有稳定公开契约，继续是 `@tessera/contracts` 的唯一入口。
- `index.test.ts`：验证根入口重新导出的运行时守卫拒绝非法资源限制、Skill ID 与网络模式。
- `index.type-test.ts`：验证领域拆分前后的根入口类型等价，以及桌面 API 频道、参数和返回值关联。
- `task-run-policy.ts`：任务执行模式、Skill、研究网络、RunPolicy 与运行资源摘要契约及运行时守卫。

## 触发器

契约文件增删、重命名或导出职责变化时更新本文。
