# contracts/src

## 地位

共享契约包的源码入口。

## 逻辑

单一入口集中导出 IPC 频道、窗口生命周期、工作区条目操作、AI 配置/连接/对话与工具增量、可恢复流式运行、Agent 变更预览、任务执行模式、内置 Skill 选择与版本化消息 Part 等跨进程类型。桌面桥接由泛型方法契约统一关联调用方式、频道、参数元组和返回值，后续按领域增长时再拆文件。

## 约束

- 类型应可在 Electron、浏览器和 Node.js 环境共同引用。
- 不导入具体运行时实现。
- IPC 调用签名只在 `DesktopApiContract` 定义一次，`DesktopApi` 与查询辅助类型必须由它推导。
- 跨进程未知载荷使用 `unknown`，不得为了方便退化为 `any`。

## 成员清单

- `index.ts`：IPC 频道、AI 配置/模型目录/正文与工具流式增量、按 task/request/sequence 恢复的运行快照、Agent Markdown 变更预览、Chat/Agent 执行模式、研究/写作内置 Skill、显式可空工作区归属、工作区最近项与任务上下文命令、版本化任务消息，以及生成桌面 API 的方法契约。
- `index.type-test.ts`：验证桌面 API 方法的调用方式、频道、参数和返回值关联不会在重构中退化。

## 触发器

契约文件增删、重命名或导出职责变化时更新本文。
