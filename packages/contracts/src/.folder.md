# contracts/src

## 地位

共享契约包的源码入口。

## 逻辑

单一入口集中导出 IPC 频道、窗口生命周期、工作区条目操作、AI 配置/连接、统一模型类型/模态/固有能力/端点绑定、MCP 服务器/工具、用户 Skill 单目录导入与批量扫描安装、研究网络模式、类型化 RunPolicy 与资源摘要、研究计划/来源读取/证据/推荐/完成进度、研究笔记与来源保存、后端无关 Project/Document/Artifact/Resource Binding 引用、对话与工具增量、版本化公开运行/工具失败、可恢复流式运行、客户端问答、Agent 变更预览、内部任务执行模式、自动/内置/用户 Skill/问答创作选择与版本化消息 Part 等跨进程类型。桌面桥接由泛型方法契约统一关联调用方式、频道、参数元组和返回值，后续按领域增长时再拆文件。

## 约束

- 类型应可在 Electron、浏览器和 Node.js 环境共同引用。
- 不导入具体运行时实现。
- IPC 调用签名只在 `DesktopApiContract` 定义一次，`DesktopApi` 与查询辅助类型必须由它推导。
- 跨进程未知载荷使用 `unknown`，不得为了方便退化为 `any`。

## 成员清单

- `index.ts`：IPC 频道、AI 配置/模型目录、MCP 服务器与工具、用户 Skill 单目录安装/扫描预览/批量安装/启停/删除及 `user:<name>` 守卫、研究网络 `system` / `direct` 联合、允许研究继承模型输出上限的类型化 RunPolicy、带稳定失败码的研究读取结果、含本轮网络模式的运行资源摘要、脱敏的单次运行解释、后端无关内容对象引用、正文与工具流式增量、版本化 `data-task-error` / `data-tool-error`（含 `toolCallId` 与 `toolName`）、按 task/request/sequence 恢复的运行快照、客户端问答/研究计划工具、Agent Markdown 变更预览、内部 Chat/Agent 执行模式、自动/问答选择与内置/用户 Skill、显式可空工作区归属、版本化任务消息，以及生成桌面 API 的方法契约。
- `index.type-test.ts`：验证研究网络与其他桌面 API 方法的调用方式、频道、参数和返回值关联，以及客户端不能提交能力开关、RunPolicy/内容对象联合不会在重构中退化。

## 触发器

契约文件增删、重命名或导出职责变化时更新本文。
