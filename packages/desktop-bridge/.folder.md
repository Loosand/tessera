# desktop-bridge

## 地位

桌面渲染层与具体宿主传输之间的平台无关桥接包。

## 逻辑

消费 `@tessera/contracts` 的唯一桌面 API 契约，把宿主提供的 `invoke`、`send`、`subscribe` 传输组装为冻结的
`DesktopApi`；Electron preload 与其他桌面宿主复用同一份方法、频道和参数映射。

## 约束

- 不依赖 Electron、Tauri、DOM、Node.js 或 Bun 专用 API。
- 每个公开方法必须从 `DesktopApiContract` 推导频道、参数与返回值。
- 创建出的 API 必须冻结，且不得暴露任意频道调用能力。

## 成员清单

- `src/`：平台无关的传输契约、桌面 API factory 与覆盖测试。
- `package.json`：包元数据、公开入口和验证脚本。
- `tsconfig.json`：TypeScript 严格类型检查配置。

## 触发器

公开 factory、传输协议、桌面 API 映射、依赖或成员变化时更新本文。
