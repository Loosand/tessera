# desktop-bridge/src

## 地位

共享桌面桥接包的源码入口。

## 逻辑

`index.ts` 从共享契约反向推导三类传输签名，并把全部桌面 API 方法映射到对应频道；测试以同一契约约束的完整
方法表逐项核对调用类型、频道、参数和订阅释放函数。

## 约束

- `DesktopApiContract` 是方法集合与调用签名的唯一事实源。
- factory 只组装窄接口，不解释载荷、不捕获错误、不维护宿主状态。
- 新增桌面方法时必须同步实现映射和完整覆盖表。

## 成员清单

- `index.ts`：`DesktopApiTransport` 与 `createDesktopApi`。
- `index.test.ts`：67 个桌面方法的冻结、完整性与传输转发回归测试。

## 触发器

源码成员、传输类型、方法映射或覆盖策略变化时更新本文。
