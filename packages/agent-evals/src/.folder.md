# agent-evals/src

## 地位

Agent Eval 的可执行源码与公开入口。

## 逻辑

`cases/` 提供固定 Suite；`evaluate.ts` 先执行硬检查，再独立计算人工质量和客观效率；
`inspection.ts` 将产品已有 Run Inspector 投影为评估指标；`report.ts` 汇总多次运行；`cli.ts` 只负责文件输入输出。

## 约束

- 评估器不得调用模型、工具或修改被测工作区。
- 硬检查只使用可重复的最终快照和事件事实，不用关键词分数替代整体人工质量。
- 缺失 Token/耗时必须标为测量不完整，不能伪造为零。
- 公开类型不绑定具体供应商。

## 成员清单

- `types.ts`：Suite、Case、运行记录、评分与报告类型。
- `rubric.ts`：统一人工评分维度与计算。
- `evaluate.ts`：硬检查、效率归一化和单次运行分级。
- `inspection.ts`：TaskRunInspection 到客观指标的窄适配。
- `parse.ts`：本地结果 JSON 的运行时校验。
- `report.ts`：多次运行聚合与 Markdown 报告。
- `cli.ts`：列出评估集或读取结果生成报告。
- `cases/`：版本化黄金任务与固定工作区材料。
- `index.ts`：公开入口。
- `index.test.ts`：目录、评分、检查、解析、适配与报告回归。

## 触发器

成员、公开导出、评分顺序或输入输出协议变化时更新本文。
