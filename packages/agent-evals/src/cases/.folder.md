# agent-evals/src/cases

## 地位

随代码版本化的 Tessera Agent 黄金任务评估集。

## 逻辑

每个 Case 固定用户请求、初始工作区、脚本化外部事件、机器预期、人工关注点与效率预算；
`index.ts` 将它们组成唯一公开 Suite。被测 runner 负责把内存工作区物化到临时目录并回收最终快照。

## 约束

- Case ID 一经发布不得改义；行为变化通过增加 version 或新 ID 表达。
- 固定材料不得依赖实时网页、当前日期、用户机器状态或未提交文件。
- 机器关键词只验证关键事实锚点，不能替代人工阅读和质量评分。
- 预算表达产品目标；真实运行更慢时记录失败，不反向放宽当次 Case。

## 成员清单

- `core-cases.ts`：直接回答、工作区理解、精确编辑、测试修复、证据综合与冲突恢复的首批任务。
- `index.ts`：`tessera-core` Suite 组装与公开目录。

## 触发器

Case、固定材料、预期、脚本事件、预算或 Suite 版本变化时更新本文。
