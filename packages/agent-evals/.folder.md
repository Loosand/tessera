# agent-evals

## 地位

Tessera 的版本化 Agent 产品评估包，保存黄金任务、评分契约与离线报告逻辑。

## 逻辑

代码内固定任务输入、工作区快照、预期结果和效率预算；评估器把一次真实运行的最终快照、工具事实、
Run Inspector 指标与人工评分合成为硬门槛、质量分和效率分。CLI 只读取结果 JSON 并输出报告，不发起模型请求。

## 约束

- 黄金任务和预算是代码资产，修改必须经过测试与评审，不根据单次结果临时放宽。
- 质量优先于效率：未完成、安全失败或人工质量不达标，不能用低 Token/低耗时抵消。
- 任务材料必须固定且不含 Secret、用户隐私或易漂移的在线内容。
- 真实运行输出默认写入被忽略的 `artifacts/agent-evals/`，不把供应商载荷提交为 fixture。

## 成员清单

- `src/`：评估契约、黄金任务、检查器、Run Inspector 适配、报告与 CLI。
- `examples/`：经同一解析器验证、可复制的运行记录 JSON 示例。
- `package.json`：包入口、测试、类型检查和报告命令。
- `tsconfig.json`：严格 TypeScript 配置。

## 触发器

评估 Schema、评分策略、黄金任务目录、包命令或依赖变化时更新本文。
