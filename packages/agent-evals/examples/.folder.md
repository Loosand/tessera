# agent-evals/examples

## 地位

可直接复制和交给报告 CLI 的评估记录格式示例。

## 逻辑

示例使用虚构模型与 revision，完整展示最终快照、工具事实、客观指标和五项人工评分；测试会通过同一运行时解析器读取它。

## 约束

- 只使用虚构数据，不保存真实供应商输出或凭据。
- Schema 变化时必须同步示例和解析测试。
- 示例不是质量基线，不能进入模型版本比较统计。

## 成员清单

- `direct-answer-run.example.json`：无工具直接回答 Case 的完整单次记录示例。

## 触发器

运行记录 Schema、人工量表或 CLI 输入格式变化时更新本文。
