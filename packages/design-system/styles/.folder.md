# styles

## 地位

Tessera 设计系统的语义 token 与跨应用基础样式事实源。

## 逻辑

本目录加载 Tailwind v4、界面字体和 Markdown 主题可选的本地字体并扫描设计系统组件；中性基准色、内容语义色与表面层级先映射为语义变量，再通过 `@theme` 暴露。

## 约束

- 组件只消费语义 token，不依赖本文件中的原始颜色值。
- 明暗主题保持相同 token 名称。
- 这里只定义全局基础样式，不放具体页面布局。

## 成员清单

- `globals.css`：Tailwind 入口、明暗主题、语义颜色、界面字体，以及 Geist、Montserrat、Nunito Sans、Space Grotesk、Open Sans、Outfit、Oxanium、Lora、JetBrains Mono 等 Typeset 精选本地字体、圆角、阴影 token 及共享轻量动效。

## 触发器

token 名称、主题策略、字体、圆角或基础焦点行为变化时更新本文。
