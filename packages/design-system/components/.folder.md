# components

## 地位

设计系统的组件目录，容纳基础 UI 以及不绑定业务数据的复合模式。

## 逻辑

`ui/` 封装行为原语；目录根部组件组合这些原语，形成设置分组等通用产品结构。

## 约束

- 复合组件从 `components/ui/` 导入基础组件，不直接依赖 Base UI。
- 组件文件使用小写 kebab-case，并保持键盘可达和响应式。

## 成员清单

- `ui/`：shadcn/ui 与图标基础组件。
- `icons/`：业务可使用的图标数据白名单。
- `activity-trace.tsx`：思考、联网搜索与工具执行共享的可展开过程轨迹容器。
- `loading-state.tsx`：长耗时任务共享的可独立复用像素网格、状态文案、耗时与可选视频反馈模式；像素网格支持运行和静止状态。
- `selection-actions.tsx`：跟随文本选区定位、承载 AI 编辑指令和异步状态的浮动操作条。
- `setting-section.tsx`：设置分组标题与内容容器。
- `setting-row.tsx`：设置项信息与控件布局。
- `tool-chips.tsx`：单条或聚合工具调用共享的紧凑状态、展开详情与文件变更预览模式。

## 触发器

组件增删、目录分层、布局契约或依赖方向变化时更新本文。
