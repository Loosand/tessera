# components/icons

## 地位

业务界面可使用的 Hugeicons 图标白名单。

## 逻辑

这里只重新导出经过评审的图标数据，包括模型能力、MCP 连接/服务器/命令、Skill 目录扫描和弹窗关闭等高频语义；实际 SVG 由 `components/ui/icon.tsx` 统一渲染。

## 约束

- 应用不得直接依赖 Hugeicons 包。
- 新增图标前先复用现有语义，避免相同动作出现多种图形语言。

## 成员清单

- `index.ts`：已允许用于导航、编辑、设置与任务输入的图标数据导出。

## 触发器

图标新增、移除、语义或底层图标库变化时更新本文。
