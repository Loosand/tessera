# components/ui

## 地位

由 shadcn/ui 风格源码、Base UI 行为原语和原生语义控件组成的基础组件目录。

## 逻辑

需要复杂浮层行为的组件封装 Base UI；普通选择等平台已有能力直接保留原生语义。两类组件统一消费语义 token 和 `cn` 工具，再由应用或复合组件按明确子路径导入。

## 约束

- 只有本目录可以直接依赖 Base UI 与具体图标渲染库。
- 原生控件不得用自绘 Portal 重复实现浏览器或桌面环境已有的菜单行为。
- shadcn CLI 生成的组件保持上游结构；定制时不得破坏公开 API 和无障碍行为。
- 不包含阅读器、工作区或 Agent 等业务状态。

## 成员清单

- `button.tsx`：按钮及其视觉变体。
- `context-menu.tsx`：右键菜单、命令项、分组与快捷键提示原语。
- `dialog.tsx`：模态对话框、遮罩、标题、说明和关闭行为原语。
- `input.tsx`：单行文本输入框。
- `textarea.tsx`：多行文本输入框。
- `message-scroller.tsx`：仅在用户贴底时自动跟随增量消息，并在离开底部后提供返回按钮。
- `popover.tsx`：上下文浮层及定位组合部件。
- `tooltip.tsx`：高密度图标控件的悬停与键盘焦点提示浮层。
- `switch.tsx`：开关控件。
- `native-select.tsx`：使用原生 `select`、`option` 与 `optgroup` 行为的单选输入。
- `slider.tsx`：基于 Base UI、带方向轨道、进度、焦点反馈和安全命中区的连续单值或范围输入。
- `separator.tsx`：水平或垂直分隔线。
- `sheet.tsx`：基于 Base UI Drawer 的右侧临时详情面板，统一焦点、关闭、遮罩和滑动行为。
- `icon.tsx`：Hugeicons 的统一包装层。

## 触发器

基础组件增删、Base UI API、视觉变体或图标边界变化时更新本文。
