# design-system

## 地位

Tessera 的共享 React 组件包与视觉系统事实边界。

## 逻辑

shadcn/ui 基础组件位于 `components/ui/`，复合模式位于 `components/`，工具与样式从包根目录按职责分开。

## 约束

- Base UI 只能由 `components/ui/` 直接使用。
- 组件遵循 `design.md`，文件使用小写 kebab-case。
- 不承载工作区、文档或 Agent 等业务状态。

## 成员清单

- `components/`：基础 UI 与复合模式组件。
- `lib/`：无状态共享工具。
- `hooks/`：跨组件复用的无业务交互 Hook。
- `styles/`：Tailwind 入口与语义 token。
- `index.ts`：根级便捷导出。
- `index.type-test.ts`：状态字面量、复合组件必填字段和控件尺寸的编译期契约。
- `components.json`：shadcn/ui 生成配置。
- `package.json`：包依赖与公开入口。
- `tsconfig.json`：类型检查配置。

## 触发器

组件分层、公共依赖、包入口或设计系统边界变化时更新本文。
