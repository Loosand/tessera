# agent-runtime/src

## 地位

Agent 运行时公共契约的源码入口。

## 逻辑

具体适配器以泛型请求进入可替换运行时，执行过程以其真实公开协议的异步事件流返回；当前 AI SDK 适配器直接使用标准 `UIMessageChunk`，本包不维护平行事件协议。工作区文件能力另以供应商无关的类型化端口连接模型工具适配器和主进程实现。

## 约束

- 运行时事件必须由具体适配器公开，不在公共端口中预设一套未被消费的默认协议。
- 取消通过 `AbortSignal` 传播，不定义隐式全局状态。

## 成员清单

- `index.ts`：权限类型、泛型运行时接口与工作区文件 capability 公开入口。
- `index.type-test.ts`：工作区文件分页与写入结果的编译期契约。
- `workspace-file-capabilities.ts`：工作区 Markdown 列表、分页读取、搜索与受批准变更的类型化 capability contract。

## 触发器

协议文件增删、事件类型或运行时接口变化时更新本文。
