# agent-runtime/src

## 地位

Agent 运行时公共契约的源码入口。

## 逻辑

具体适配器以泛型请求进入可替换运行时，执行过程以其真实公开协议的异步事件流返回；当前 AI SDK 适配器直接使用标准 `UIMessageChunk`，本包不维护平行事件协议。工作区 read/edit/write（含超长单行 UTF-8 续读游标）与前台 bash 能力分别以供应商无关的类型化端口连接模型工具适配器和主进程实现。

## 约束

- 运行时事件必须由具体适配器公开，不在公共端口中预设一套未被消费的默认协议。
- 取消通过 `AbortSignal` 传播，不定义隐式全局状态。
- ExecutionEnvironment 必须公开隔离/Secret/网络事实，并在进程树和输出完全收口后才返回。

## 成员清单

- `index.ts`：权限类型、泛型运行时接口与工作区四核心 capability 公开入口。
- `index.type-test.ts`：工作区 read/edit/write/bash、分页/单行续读、读写级别和稳定终态的编译期契约。
- `workspace-file-capabilities.ts`：工作区 Markdown read/edit/write 文件核心与 UTF-8 单行分段游标。
- `execution-environment.ts`：可替换命令执行环境、工作区读写级别与有界命令结果契约。

## 触发器

协议文件增删、事件类型或运行时接口变化时更新本文。
