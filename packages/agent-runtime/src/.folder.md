# agent-runtime/src

## 地位

Agent 运行时公共契约的源码入口。

## 逻辑

具体适配器以泛型请求进入可替换运行时，执行过程以保留领域类型的异步事件流返回；基础事件由事件映射派生，调用方可按判别字段或工具输出类型精确收窄。

## 约束

- 事件必须可序列化或可明确适配。
- 取消通过 `AbortSignal` 传播，不定义隐式全局状态。
- 新增基础事件时先扩展事件映射，再由映射派生事件联合和事件类型。

## 成员清单

- `index.ts`：默认请求、事件映射、事件提取器、权限类型与可由具体适配器收窄的泛型运行时接口。
- `index.type-test.ts`：判别字段、工具输出和事件提取能力的编译期契约。

## 触发器

协议文件增删、事件类型或运行时接口变化时更新本文。
