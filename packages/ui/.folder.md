# ui

## 地位

Tessera 的共享 React 组件包和设计系统边界。

## 逻辑

UI 按 `tokens → primitives → base → patterns → features` 分层，通过包入口向应用暴露稳定组件。

## 约束

- Base UI 只能由 primitives 层直接使用。
- 组件遵循 `design.md`，文件使用小写 kebab-case。
- 不承载工作区、文档或 Agent 等业务状态。

## 成员清单

- `src/`：组件源码与公开导出。
- `package.json`：包依赖与公开入口。
- `tsconfig.json`：类型检查配置。

## 触发器

组件分层、公共依赖、包入口或设计系统边界变化时更新本文。
