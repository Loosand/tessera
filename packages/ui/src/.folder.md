# ui/src

## 地位

共享 UI 组件的源码与公开 API 入口。

## 逻辑

具体组件由独立 kebab-case 文件实现，`index.ts` 只汇总经过评审的公共导出。

## 约束

- 公共组件必须有明确 props 类型和语义 HTML。
- 业务应用不得依赖未从 `index.ts` 导出的内部文件。
- 新的通用交互组件按 `design.md` 的分层放入对应子目录。

## 成员清单

- `capability-card.tsx`：当前脚手架使用的能力摘要组件。
- `index.ts`：包的公共导出入口。

## 触发器

组件增删、重命名、公共导出或目录分层变化时更新本文。
