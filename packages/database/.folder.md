# database

## 地位

Tessera 本地 SQLite 数据层的唯一低层入口。

## 逻辑

`schema.ts` 提供 Drizzle 类型结构与行类型事实源，仓储输入从行类型裁剪推导；`migrations/` 前向演进物理表并保留迁移 ID 字面量联合，`client.ts` 配置连接，仓储模块提供非敏感应用偏好、内容库、托管工作区、动态资源、Artifact、项目操作审计、研究计划/来源/证据/推荐与保存关系控制层、带可变内置/用户 Skill 默认值和可恢复等待输入状态的任务会话、用户 Skill 安装目录、完整逐轮 RunPolicy/资源摘要、AI SDK 生命周期完成指标与运行检查点、Agent 变更审批，以及按 `config_id` 区分的供应商和 MCP 连接实例稳定读写操作。

## 约束

- Markdown 正文始终留在工作区文件中；数据库只保存可重建索引和运行状态。
- 只有 Electron 主进程或其核心服务可以打开连接，渲染层不得直接依赖本包。
- schema 变化必须新增迁移并经过测试，禁止编辑已经发布的迁移。
- 仓储输入和状态联合必须从 Drizzle 行类型推导，不得重复手写表字段契约。
- 外键始终开启；磁盘数据库默认使用 WAL 与普通同步级别。

## 成员清单

- `client.ts`：SQLite 连接、目录创建、PRAGMA 和 Drizzle 装配。
- `schema.ts`：非敏感应用偏好、工作区索引与最近列表隐藏状态、AI 协议及具名连接配置、MCP 连接、用户 Skill 安装目录、带等待输入标记的通用任务/版本化消息、逐轮执行策略、研究运行/问题/来源/证据/推荐、生命周期完成指标，以及后续 Agent 事件与权限表。
- `app-setting-repository.ts`：按键查询和幂等保存由主进程验证的非敏感应用偏好。
- `ai-provider-config-repository.ts`：按连接实例保存协议、显示名、模型 JSON 与 safeStorage 密文，并提供查询、幂等保存和删除。
- `mcp-server-config-repository.ts`：保存 MCP 传输、信任/启用状态、逐工具禁用清单与 safeStorage 密文，并提供查询、幂等保存和删除。
- `user-skill-config-repository.ts`：保存用户 Skill 稳定 ID、描述、启用状态、安装统计与时间，并提供查询、幂等保存、启停和删除。
- `workspace-repository.ts`：工作区最近使用列表、单项查询、可恢复隐藏与幂等保存；普通打开只刷新显示信息和时间，不覆盖既有托管内容库身份。
- `content-domain-repository.ts`：内容库、托管工作区、文档稳定索引、动态资源、Artifact、项目操作审计与任务当前项目关系。
- `task-session-repository.ts`：下一轮 Skill 默认值/工作区任务列表、跨工作区最近任务、等待用户输入状态兼容映射、主进程运行状态收口、逐条版本化消息的事务读写、重命名与级联删除。
- `task-run-repository.ts`：实际 mode/Skill/思考/联网策略、完整 RunPolicy、资源摘要、完成原因、Token/缓存/耗时指标、重复幂等且 lastSequence 单调的流事件检查点、按请求精确/按任务最新恢复读取、崩溃中断标记与清理。
- `research-repository.ts`：绑定 task run 的研究计划、问题、规范化来源、读取结果摘要、证据关系、来源推荐/保存关系、完成状态，以及跨新 request 的显式研究状态克隆。
- `agent-change-repository.ts`：冻结的 Markdown 变更提案、人工决策、冲突与写入结果审计。
- `migrations/`：有序、幂等的前向迁移。
- `database.test.ts`：在 Node/Vitest 中运行结构、应用偏好、研究计划/来源/证据/推荐/覆盖恢复、旧 Chat 快照迁移、最近工作区隐藏恢复、任务等待输入/重命名/删除、用户 Skill 目录、Agent 工作区约束、AI/MCP 加密配置恢复、运行事件乱序/重复恢复、幂等性和级联删除测试。
- `index.ts`：包的公共导出入口。
- `package.json`、`tsconfig.json`：依赖、脚本和类型检查配置。

## 触发器

表结构、迁移策略、连接参数、公共导出或目录成员变化时更新本文。
