# database

## 地位

Tessera 本地 SQLite 数据层的唯一低层入口。

## 逻辑

`schema.ts` 提供 Drizzle 类型结构与行类型事实源，仓储输入从行类型裁剪推导；`migrations/` 前向演进物理表并保留迁移 ID 字面量联合，`client.ts` 配置连接，仓储模块提供工作区、带可选 Skill 和可恢复等待输入状态的任务会话、AI 运行检查点、Agent 变更审批与按 `config_id` 区分的供应商连接实例稳定读写操作。

## 约束

- Markdown 正文始终留在工作区文件中；数据库只保存可重建索引和运行状态。
- 只有 Electron 主进程或其核心服务可以打开连接，渲染层不得直接依赖本包。
- schema 变化必须新增迁移并经过测试，禁止编辑已经发布的迁移。
- 仓储输入和状态联合必须从 Drizzle 行类型推导，不得重复手写表字段契约。
- 外键始终开启；磁盘数据库默认使用 WAL 与普通同步级别。

## 成员清单

- `client.ts`：SQLite 连接、目录创建、PRAGMA 和 Drizzle 装配。
- `schema.ts`：工作区索引与最近列表隐藏状态、AI 协议及具名连接配置、带等待输入标记的通用任务/版本化消息，以及后续 Agent 事件与权限表。
- `ai-provider-config-repository.ts`：按连接实例保存协议、显示名、模型 JSON 与 safeStorage 密文，并提供查询、幂等保存和删除。
- `workspace-repository.ts`：工作区最近使用列表、单项查询、可恢复隐藏与幂等保存。
- `task-session-repository.ts`：可选 Skill/工作区任务列表、跨工作区最近任务、等待用户输入状态兼容映射、逐条版本化消息的事务读写、重命名与级联删除。
- `task-run-repository.ts`：AI 运行元数据、按序流事件检查点、崩溃中断标记、恢复读取与清理。
- `agent-change-repository.ts`：冻结的 Markdown 变更提案、人工决策、冲突与写入结果审计。
- `migrations/`：有序、幂等的前向迁移。
- `database.test.ts`：在 Node/Vitest 中运行结构、旧 Chat 快照迁移、最近工作区隐藏恢复、任务等待输入/重命名/删除、Agent 工作区约束、运行事件恢复、幂等性和级联删除测试。
- `index.ts`：包的公共导出入口。
- `package.json`、`tsconfig.json`：依赖、脚本和类型检查配置。
