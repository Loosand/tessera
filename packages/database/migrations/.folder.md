# migrations

## 地位

本地 SQLite 数据库的前向版本历史与执行入口。

## 逻辑

每个迁移拥有稳定 ID 和有序 SQL；执行器在单个事务中应用缺失迁移并记录结果。

## 约束

- 已发布迁移不可修改，只能追加新迁移。
- 迁移必须幂等执行，并与 `schema.ts` 的最终结构一致。
- SQL 不读取用户 Markdown 正文，也不绕过外键约束。

## 成员清单

- `0000-foundation.ts`：初始工作区索引与 Agent 状态表。
- `0001-ai-provider-configs.ts`：供应商配置、模型状态与加密 API Key 密文表。
- `0002-task-sessions.ts`：通用 Chat/Agent 任务会话、版本化消息与旧 Chat 快照迁移。
- `0003-workspace-recents.ts`：工作区从最近列表可恢复移除所需的隐藏时间。
- `0004-agent-runs-and-changes.ts`：任务运行事件检查点与 Agent Markdown 变更提案、审批和结果审计。
- `0005-ai-provider-connections.ts`：将供应商单例配置迁移为按 `config_id` 区分的具名连接，并为任务运行补充连接实例标识。
- `0006-task-skills.ts`：为任务会话补充与 Chat/Agent 执行模式正交的可选内置 Skill 标识。
- `0007-task-waiting-input.ts`：为任务会话追加可恢复的等待用户输入标记，不重写旧状态约束。
- `types.ts`：迁移契约。
- `index.ts`：迁移清单和执行器。

## 触发器

新增迁移、迁移契约、执行顺序或记录表结构变化时更新本文。
