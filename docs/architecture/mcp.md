## 地位

MCP 是 Tessera 连接外部工具的协议边界，不是模型固有能力，也不属于某个 AI 供应商端点。服务器配置决定 Tessera
可以连接哪些外部程序；模型是否能规划工具调用仍由模型事实和当前 Agent 运行策略决定；真正执行由主进程信任边界和
AI SDK 人工审批共同控制。

实现参考 Cherry Studio 的分层方式：配置实体、传输、运行时连接池、能力发现和 Agent 工具适配彼此独立。Tessera
首版只取主干，不复制其完整管理面：设置页使用服务器目录与详情工作区，能力列表按协议动态发现；OAuth、资源、Prompt
和日志留给后续独立模块。

## 数据模型

`mcp_server_configs` 保存：

- 稳定服务器 ID、显示名称、说明、传输类型、启用与信任状态；
- stdio 命令和参数，或远程 HTTP(S) URL；
- 连接超时与逐工具禁用清单；
- 环境变量、请求头的 Electron `safeStorage` 密文；
- 最后更新时间。

公开 IPC 只返回 `envConfigured` / `headersConfigured`，不回传密文或明文。连接状态、握手得到的服务器名称与版本、
最近错误只存在于主进程内存，重启后重新发现，不伪造成持久化事实。

当前禁用工具按 MCP 原始工具名保存。公开给 AI SDK 的工具 ID 使用服务器 ID 哈希、规范化工具名和工具名哈希组合，
既避免泄露可读服务器标识，也避免规范化后的名称碰撞。

## 传输与连接生命周期

已实现三种客户端传输：

| 传输 | 用途 | 约束 |
| --- | --- | --- |
| `stdio` | 本机 MCP 进程 | 命令和参数直接交给 SDK，不经过 Shell 展开；只在主进程启动；合并最小默认环境与加密环境变量 |
| `streamable-http` | 当前远程 MCP 服务 | 只允许不含账号密码的 HTTP(S) URL；请求头在主进程解密 |
| `sse` | 旧 MCP 服务兼容 | 与 HTTP 相同的 URL/请求头边界，不作为新服务首选 |

运行时按影响连接的配置指纹复用连接。传输、命令、参数、URL、超时或秘密改变时关闭旧连接；停用、删除和应用退出时
释放连接。停用服务器的“检测连接”只完成一次握手与工具发现，检测结束立即关闭连接，避免后台遗留本地子进程。

工具列表支持 MCP cursor 分页，并限制最多 20 页。单次工具调用设置服务器超时、中止信号和 1 MiB 输出上限。

## 信任与秘密

服务器保存与服务器启用是两个动作：

1. 用户可以先保存一个停用、未信任的草稿。
2. 连接或启用前必须显式确认信任；伪造 IPC 也会在主进程被拒绝。
3. 秘密写入前校验真实下游边界：环境变量名拒绝 `=` / NUL，请求头名称必须是合法 HTTP token，值必须能安全进入 HTTP Header。
4. 系统安全存储不可用时，拒绝保存新的环境变量或请求头；已有密文可以继续保留或显式移除。
5. renderer 永远不读取已保存秘密；编辑时留空表示保持原值。
6. 连接错误、工具错误和工具输出在离开 MCP 边界前替换已配置秘密值，避免外部服务器回显凭据。

历史密文也会在解密后、建立连接前按同一规则复核；无效配置进入稳定 `error` 状态并返回可操作提示，不把 Fetch
`ByteString` 或子进程环境错误暴露给用户。

信任代表“允许 Tessera 启动或连接这个外部服务器”，不代表自动批准其工具动作。用户应把 stdio 命令视为本机程序，
把远程 MCP 视为可接收工具输入和所授权秘密的外部服务。

## Agent 集成与审批

```text
已启用且已信任的服务器
  -> 主进程连接并发现工具
  -> 应用逐工具禁用清单
  -> 转为 ExternalAgentTool
  -> AI SDK dynamicTool(needsApproval = true)
  -> 模型提出调用
  -> renderer 展示现有标准工具审批
  -> 用户批准后，下一轮再次核对服务器与工具仍启用
  -> 主进程调用 MCP 并裁剪/脱敏输出
```

当前 MCP 工具只注入有工作区授权的 Agent 入口，普通 Chat 不获得外部工具。每个动态 MCP 工具固定
`needsApproval = true`，不支持服务器级或工具级自动批准；MCP annotations 只用于详情提示，只读提示也不能跳过批准。
用户拒绝后，Agent instructions 禁止用重复或相似调用绕过决定。

工具调用前再次读取 SQLite 配置，防止运行期间停用服务器或工具后，旧 Agent 工具闭包继续执行。调用使用当前 turn 的
中止信号；页面离开不隐式取消，用户停止、窗口销毁或应用退出会终止运行。

## 设置交互

MCP 使用与模型供应商一致的主从结构，但职责独立：

- 左侧目录展示传输类型、启用状态和运行状态；
- 右侧详情展示连接摘要、握手身份、加密变量状态和工具清单；
- 设置按钮打开连接编辑 Dialog；创建与修改复用同一配置面；
- “检测连接”完成握手和工具发现；工具逐项开关即时持久化；
- 删除需要二次确认，并关闭活动连接、删除配置与密文，但不卸载外部程序。
