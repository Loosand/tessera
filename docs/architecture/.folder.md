# docs/architecture

## 地位

记录需要跨越应用和共享包维护的工程机制。

## 逻辑

每份文档链接代码源头，说明数据事实源、运行时边界、已实现协议和后续决策条件。

## 约束

- 文档开头标明代码源头和能力状态。
- 使用「已实现」「部分实现」「规划」区分事实与意图。
- 行为变化时由源文件 Header 的 `[DOC]` 链接触发同步。
- 外部调研只保留影响当前决策的结论，不在本目录长期保存产品对比记录。

## 成员清单

- `agent-kernel-and-capability-runtime.md`：Pi 风格轻量 Agent Kernel、能力注册与按需路由、有界 Context Compiler、渐进式资源加载、领域命令和事件投影的收敛架构。
- `unified-creation-agent.md`：已确认的统一创作交互、动态运行策略，以及数据库/托管内容库/外部工作区的存储探索。
- `adr-0001-content-storage-experiment.md`：托管内容库实验基线、三个存储候选的统一指标和最终决策门槛；不构成最终选型。
- `ai-chat-agent-todo.md`：供应商运行时、普通对话、工作区 Agent 与统一创作运行时的实施顺序和验收门槛。
- `ai-providers.md`：供应商协议适配器、具名连接、可选模型目录、AI SDK 适配与页面级流式恢复边界。
- `ai-observability.md`：AI SDK 官方开发日志、主进程 Viewer 边界、reasoning 可见性语义、SQLite 脱敏运行汇总与生产诊断规划。
- `research-workflow.md`：主动研究的计划、搜索、阅读、证据、完成门槛、来源推荐与网页读取层级。
- `mcp.md`：MCP 服务器安全配置、传输连接池、能力发现、逐工具开关与 Agent 人工审批边界。
- `task-navigation.md`：当前 Chat/Agent 兼容会话、目标动态资源关联、历史/后台运行恢复与导航顺序。
- `skill-system.md`：标准 `SKILL.md`、内置注册表、用户目录托管导入/启停/删除、渐进式模型加载、任务选择与权限边界。
- `database.md`：SQLite 数据边界、连接生命周期和迁移机制。
- `editor.md`：Typeset 主题、TipTap/CodeMirror 编辑表面、Markdown 往返、性能基准、草稿同步和 Agent 修改边界。
- `local-version-history-and-git-workspaces.md`：本地文档版本历史、已有 Git 工作区轻量管理及两套版本语义的协作边界。
- `plugin-system.md`：插件包、贡献点、隔离运行时、能力权限、安装更新和社区目录的架构边界。
- `release.md`：macOS Alpha 版本、Tag、签名、公证、GitHub Pre-release 与公共下载边界。
