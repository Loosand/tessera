# docs/architecture

## 地位

解释跨目录工程机制的架构深文档目录。

## 逻辑

每份文档链接代码源头，用稳定机制说明替代易失真的文件枚举。

## 约束

- 文档开头标明代码源头。
- 能力使用「已实现」「部分实现」「规划」状态。
- 代码行为变化时由对应 Source Header 的 `[DOC]` 触发同步。

## 成员清单

- `fractal-documentation-guide.md`：分形文档的写作与维护规则。
- `database.md`：SQLite 数据边界、连接策略和迁移机制。
- `editor.md`：TipTap、Markdown 往返、草稿同步与保存边界。
- `markdown-editor-evaluation.md`：Markdown 编辑器的区块化体验、技术路线、主题 ABI、性能风险与评测计划。

## 触发器

新增或删除深文档、文档事实源或状态约定变化时更新本文。
