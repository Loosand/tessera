# quality

## 地位

保存跨模型、供应商、Prompt、Reader 和运行时版本可重复比较的产品级质量基线。

## 逻辑

每份记录固定输入场景、机器检查条件、环境边界、运行标识、实际指标和已知限制；事实来自运行事件与数据库审计，截图只作为补充观察。

## 约束

- 不保存 API Key、Cookie、代理地址、用户隐私正文或供应商加密载荷。
- 通过与失败都如实记录；不得为了得到绿色结果放宽当次基线。
- 记录只用于校准 Tessera 行为，不作为外部产品宣传或竞品事实源。

## 成员清单

- `agent-eval-method.md`：代码化黄金任务、硬门槛、人工质量、客观效率、重复运行与报告协议。
- `research-fkj-golden-run.md`：统一 FKJ 显式研究场景的真实供应商端到端黄金运行记录。

## 触发器

黄金场景、审计条件、运行时工作流或实际基线结果变化时更新本文。
