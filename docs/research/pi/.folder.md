# docs/research/pi

## 地位

固定 Pi 源码版本，以 `packages/coding-agent` 为主线，拆解其 Agent Kernel、产品会话运行时、上下文、工具、扩展和嵌入协议，形成 Tessera 可执行的对照结论。

## 逻辑

`README.md` 固定研究范围和证据口径；专题文档从包边界与入口开始，逐层进入 Agent loop、`AgentSession`、会话树、上下文压缩、工具安全、扩展与 Skills、模型和运行模式，最后在路线图中合并采纳顺序。

## 约束

- Pi 事实默认对应提交 `853a80d26c90a14c1886f0ebb8ffaae133ca2185`；变更版本必须重新核验相关结论。
- 研究以 `.local/pi/packages/coding-agent` 为主，只有解释直接依赖时才下钻 `packages/agent` 与 `packages/ai`。
- 源码引用使用 `.local/pi` 下的仓库相对路径和具体符号；本目录不复制 Pi 源码。
- 每篇专题至少包含范围、核心对象、关键数据流、优点、局限、Tessera 对照和建议。
- `AgentHarness` 必须标记为未完成 scaffold，不能与当前可运行的 `AgentSession` 主链混写。
- Pi 的 Project Trust、扩展加载和本机执行权限是不同边界，不能把输入加载保护描述成沙箱。

## 成员清单

- `README.md`：研究范围、证据规则、专题地图和结论总览。
- `system-stack-and-runtime-boundaries.md`：包分层、启动装配、cwd 重绑定、当前主链与新 Harness 边界。
- `agent-kernel-loop-and-tool-execution.md`：Agent 状态机、模型 turn、消息队列、工具批次、并发和事件顺序。
- `agent-session-orchestration.md`：`AgentSession` 的会话编排、重试、扩展接线、动态刷新和职责债务。
- `session-tree-persistence-and-recovery.md`：JSONL 会话树、分支、迁移、上下文投影、恢复能力与限制。
- `context-system-prompt-and-compaction.md`：动态系统提示词、消息转换、Token 估算、自动压缩与分支摘要。
- `tools-files-shell-and-security.md`：内置文件/Shell 工具、路径和输出预算、写入并发、Project Trust 与隔离边界。
- `extensions-skills-and-capability-assembly.md`：资源发现、扩展 ABI、Runner、工具装配、Skills 渐进加载与供应链风险。
- `models-providers-and-runtime-routing.md`：Provider 组合、认证快照、模型恢复、范围解析和请求变换。
- `run-modes-sdk-rpc-and-ui-projection.md`：Interactive、Print/JSON、RPC、SDK 四种入口及其共享运行语义。
- `tessera-adoption-roadmap.md`：Pi 设计对 Tessera 的采纳顺序、拒绝项、验收门槛与目标拆分。
