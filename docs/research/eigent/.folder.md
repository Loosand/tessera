# docs/research/eigent

## 地位

固定 Eigent 源码版本，按领域拆解其 AI Agent 产品与工程实现，并形成 Tessera 可执行的对照结论。

## 逻辑

`README.md` 是研究入口和进度表；专题文档从系统边界开始，依次拆解 Agent、工作群、上下文、工作区、MCP、
Skills、浏览器、调度、附件与 UI，最后在路线图中合并跨领域依赖和实施顺序。

## 约束

- Eigent 事实默认对应提交 `d3089558c6e0021eed58270b49893835b02ec4e9`，变更版本必须重新核验相关结论。
- 源码引用使用 `.local/eigent` 下的仓库相对路径和具体符号；本目录不复制 Eigent 源码。
- 每篇专题至少包含范围、核心对象、关键数据流、优点、局限、Tessera 对照和建议。
- UI 截图只用于识别布局意图，行为结论仍以源码和状态流为准。

## 成员清单

- `README.md`：研究范围、证据规则、专题地图和结论总览。
- `system-stack-and-runtime-boundaries.md`：技术选型、进程拓扑、部署形态与安全边界。
- `agent-runtime-and-tool-assembly.md`：单 Agent 生命周期、模型构造、工具装配、事件协议与人工介入。
- `models-providers-and-capability-routing.md`：模型目录、供应商配置、工具验证、路由与能力事实。
- `workforce-and-multi-agent-orchestration.md`：工作群分解、Worker 调度、失败恢复、侧栏投影与多 Agent 边界。
- `context-memory-and-compaction.md`：热上下文、本地持久记忆、预算、快照、压缩与跨重启续轮。
- `workspace-files-and-artifacts.md`：Space/Project/Run、工作目录模式、overlay/apply 与 Artifact 审查。
- `mcp-and-connectors.md`：MCP 配置、市场、Connector Gateway、Agent 装配、Secrets 与调用审批。
- `skills-system.md`：Skill 包、扫描导入、配置作用域、渐进加载、Agent 绑定、资源与安全边界。
- `browser-cdp-and-cookie-management.md`：CDP 浏览器池、会话隔离、登录身份、Cookie、预览和审计边界。
- `attachments-execution-context-and-rag.md`：附件输入、运行绑定、实际使用投影、检索与引用闭环。
- `scheduling-triggers-and-remote-control.md`：Schedule/Webhook/Slack 的触发、投递、桌面执行、恢复与远控协议。
- `ui-progress-inspection-and-information-architecture.md`：三栏信息架构、Run 选择、进度、执行上下文、产物、Preview、Agent Pool 与视觉系统。
- `tessera-adoption-roadmap.md`：跨专题目标对象、依赖图、优先级、Epic、验收门槛和不采纳清单。
