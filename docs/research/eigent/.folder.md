# docs/research/eigent

## 地位

固定 Eigent 源码版本，按领域拆解其 AI Agent 产品与工程实现，并形成 Tessera 可执行的对照结论。

## 逻辑

`README.md` 是研究入口和进度表；专题文档从系统边界开始，依次拆解 Agent、工作群、上下文、工作区、MCP、
Skills、浏览器、调度、附件与 UI，最后在路线图中合并跨领域依赖和实施顺序。

## 约束

- Eigent 事实默认对应提交 `d3089558c6e0021eed58270b49893835b02ec4e9`，变更版本必须重新核验相关结论。
- 源码引用使用 `.local/eigent` 下的仓库相对路径和具体符号；本目录不复制 Eigent 源码。
- 每篇专题至少包含范围、核心对象、关键数据流、优点、局限、Tessera 对照和建议。
- UI 截图只用于识别布局意图，行为结论仍以源码和状态流为准。

## 成员清单

- `README.md`：研究范围、证据规则、专题地图和结论总览。
- `system-stack-and-runtime-boundaries.md`：技术选型、进程拓扑、部署形态与安全边界。
- `agent-runtime-and-tool-assembly.md`：单 Agent 生命周期、模型构造、工具装配、事件协议与人工介入。

## 触发器

Eigent 固定版本、专题清单、研究状态、关键结论或成员文件变化时更新本文。
