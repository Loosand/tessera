# capabilities

## 地位

Tauri WebView 可调用平台能力的最小权限声明目录。

## 逻辑

主窗口只获得两个应用命令、总事件监听、启动后显示窗口和隐藏标题栏拖动能力；业务调用还要继续经过命令内频道 allowlist。

## 约束

- 不授予文件系统、Shell、进程、HTTP 或数据库通配权限。
- capability 只能绑定受信任的 `main` 窗口。
- 应用权限只能来自 `build.rs` 中声明的 `desktop_invoke` 与 `desktop_send`。

## 成员清单

- `main.json`：主窗口最小 capability。

## 触发器

前端新增 Tauri API 调用或窗口标签变化时更新本文。
