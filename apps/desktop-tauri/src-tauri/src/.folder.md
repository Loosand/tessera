# src

## 地位

Tauri 对照壳的 Rust 运行时实现。

## 逻辑

库入口注册 `desktop_invoke`、`desktop_send` 和窗口关闭事件；纯分发函数验证频道、参数数量并生成首屏空态，idle / pending / approved 原子状态机保证关闭保存握手只发一次且失败可重试，二进制入口只负责启动库。

## 约束

- 禁止根据任意字符串动态执行命令、文件操作或进程操作。
- 新增频道时同时补 allowlist、分发语义和单元测试。
- 关闭事件必须继续经过 renderer 保存握手；无 pending 请求不得确认，任何原生失败都必须回到 idle。

## 成员清单

- `lib.rs`：严格 allowlist、空态分发、事件 envelope、关闭握手与测试。
- `main.rs`：桌面二进制入口。

## 触发器

命令、事件、状态或运行入口变化时更新本文。
