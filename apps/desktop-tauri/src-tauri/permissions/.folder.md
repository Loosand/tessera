# permissions

## 地位

Tauri 应用自定义命令的细粒度 ACL 权限目录。

## 逻辑

`build.rs` 的 `AppManifest::commands` 在 `autogenerated/` 中为两个应用命令生成对应的 allow / deny 权限，主窗口 capability 只引用 allow 权限。

## 约束

- `autogenerated/` 内容由 Tauri 构建生成，不手工修改。
- 新增命令时必须同步 `build.rs`、主窗口 capability 和本目录说明。

## 成员清单

- `autogenerated/`：Tauri 根据应用命令清单生成的权限文件。

## 触发器

应用命令清单、权限生成方式或目录成员变化时更新本文。
