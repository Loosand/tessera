# src-tauri

## 地位

Tauri v2 原生应用、构建和权限边界。

## 逻辑

Cargo 构建原生壳并从应用命令清单生成细粒度权限，`tauri.conf.json` 组合共享前端，`capabilities/` 只向主窗口授予所需能力，`src/` 通过两个泛型命令分发桌面频道并发出单一事件流。

## 约束

- 所有来自 WebView 的频道必须先通过静态 allowlist。
- 自定义命令必须同时出现在 `AppManifest` 和主窗口 capability 中。
- 首期只返回类型正确的只读空态；未实现的有副作用能力必须明确拒绝。
- 不直接暴露 Tauri 文件系统、Shell、数据库或进程插件给 WebView。

## 成员清单

- `src/`：Rust 入口、频道分发、关闭握手与测试。
- `capabilities/`：主窗口最小权限声明。
- `permissions/`：由应用命令清单生成的 allow/deny 权限。
- `build.rs`：Tauri 构建入口与两个应用命令的 ACL 清单。
- `Cargo.toml`、`Cargo.lock`：Rust 包与锁定依赖。
- `tauri.conf.json`：窗口、CSP、bundle 与前端命令配置。

## 触发器

Rust 依赖、命令入口、权限、窗口或发行配置变化时更新本文。
