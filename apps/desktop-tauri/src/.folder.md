# src

## 地位

Tauri WebView 在共享 renderer 之前执行的平台启动层。

## 逻辑

`main.ts` 预先建立单一事件监听，把 Tauri 私有 envelope 还原为桌面订阅参数，通过共享 bridge 安装冻结的 `window.tessera`，并把 Rust rejection 规范化为 renderer 可识别的 `Error`，再加载共享 renderer；同时适配隐藏标题栏拖动和启动失败界面。

## 约束

- 动态加载共享 renderer 前必须完成事件监听和 bridge 安装。
- 不在本目录复制业务组件或 67 个桌面 API 方法映射。
- transport 只调用 Rust 暴露的 `desktop_invoke` 与 `desktop_send`。

## 成员清单

- `main.ts`：Tauri transport、总事件监听、拖动区与 renderer 启动入口。
- `tauri-error.ts`：把 Tauri 任意 rejection 规范化为保留可读消息的 `Error`。
- `tauri-error.test.ts`：字符串、结构化和未知 rejection 的错误保真回归测试。
- `tauri.css`：只属于 Tauri 壳的启动失败与拖动兼容样式。

## 触发器

启动顺序、事件 envelope、transport 或标题栏交互变化时更新本文。
