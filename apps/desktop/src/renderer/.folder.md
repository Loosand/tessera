# renderer

## 地位

Electron 渲染层的 HTML 入口与 React 应用目录。

## 逻辑

`index.html` 提供挂载点与内容安全策略，`src/` 初始化并渲染 React 应用。

## 约束

- 不启用 Node.js 集成。
- 所有平台能力通过 `window.tessera` 窄接口访问。
- CSP 只额外允许 HTTPS 图片，用于无 Referer 加载联网搜索来源的 favicon；脚本和主动网络连接仍保持同源限制。

## 成员清单

- `index.html`：渲染层 HTML 入口与收窄的内容安全策略。
- `src/`：React 源码与样式。

## 触发器

HTML 入口、渲染框架或安全桥使用方式变化时更新本文。
