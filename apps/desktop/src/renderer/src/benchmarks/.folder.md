# benchmarks

## 地位

桌面渲染进程内的真实编辑器性能基准入口。

## 逻辑

使用固定 Markdown 语料挂载与产品相同 schema、编辑表面和顶层区块手柄，分段测量 Markdown 解析与 ProseMirror 建树，并采集渲染、输入、序列化、hover、滚动与内存，再把结构化结果交给独立 Electron runner。

## 约束

- 基准入口只在 `?benchmark=editor` 下动态加载，不得进入正常产品生命周期。
- 语料必须确定生成，指标必须保留原始样本和分位数，禁止只输出单次耗时。
- 默认命令只报告；CI 阈值检查必须由显式 `--check` 开启。
- 基准使用生产构建和隐藏的独立 BrowserWindow，关闭后台节流但不关闭 GPU。

## 成员清单

- `editor-benchmark-corpus.ts`：按字符量、块数量和复杂节点生成固定语料矩阵。
- `editor-benchmark-corpus.test.ts`：语料规模、结构特征与确定性测试。
- `editor-benchmark.tsx`：真实 TipTap/React 表面的计时、帧与内存采集。

## 触发器

编辑器 schema、性能指标、语料规模、挂载路径或成员变化时更新本文。
