# hooks

## 地位

渲染层跨组件状态与副作用的组合入口。

## 逻辑

将预加载层能力组织成稳定的 React 状态和操作，统一协调应用级模型快照、编辑器 flush、串行保存与窗口关闭确认，页面组件只消费领域状态。

## 约束

- 不直接导入 Electron 或 Node.js 模块。
- 异步工作区切换必须拒绝过期结果。
- 文件正文不写入渲染层持久化存储。

## 成员清单

- `use-workspace.ts`：工作区恢复、最近项显示/Finder 定位/路径复制/可恢复移除、文件/目录索引、条目操作、文档历史、串行自动保存与冲突处理。
- `use-app-preferences.ts`：主题、全局字体、圆角、Typeset、默认编辑模式与拼写检查的本地持久化和样式副作用。
- `typeset-preferences.ts`：精选 Markdown 字体目录及其运行时值守卫、节奏范围、参考/随机预设、旧偏好迁移与 CSS 变量映射。
- `typeset-preferences.test.ts`：参考/随机预设、自定义值、旧设置迁移和 CSS 变量回归测试。
- `use-ai-models.ts`：以应用级单例快照订阅 SQLite 供应商配置变更，只把已启用 Chat 模型及其连接地址暴露给任务页；重读期间保留旧快照，并持久化非敏感默认模型键。
- `use-ai-models.test.ts`：任务页供应商、密钥与模型启用筛选，以及共享 stale-while-revalidate 快照的单元测试。
- `use-tasks.ts`：管理可选工作区的统一任务会话；工作区资源刷新只更新可选历史而不替换当前任务，显式导航再创建或切换会话；独立草稿与工作区草稿只在内部选择工具权限，用户可在每轮发送前切换创作模式，并持久化下一轮默认值、跨工作区最近任务、首次发送懒创建、重命名/删除和版本化消息 Part。
- `use-user-skills.ts`：订阅用户 Skill 目录变更，协调列表刷新、系统目录选择器单个导入、递归扫描预览、勾选批量安装、启停、删除和错误状态。
- `use-user-skills.test.ts`：主进程版本错配与普通 Skill 领域错误的用户可读文案回归测试。

## 触发器

Hook 成员、领域状态或副作用边界变化时更新本文。
