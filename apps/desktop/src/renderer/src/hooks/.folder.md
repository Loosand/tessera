# hooks

## 地位

渲染层跨组件状态与副作用的组合入口。

## 逻辑

将预加载层能力组织成稳定的 React 状态和操作，统一协调编辑器 flush、串行保存与窗口关闭确认，页面组件只消费领域状态。

## 约束

- 不直接导入 Electron 或 Node.js 模块。
- 异步工作区切换必须拒绝过期结果。
- 文件正文不写入渲染层持久化存储。

## 成员清单

- `use-workspace.ts`：工作区恢复、最近项显示/Finder 定位/路径复制/可恢复移除、文件/目录索引、条目操作、文档历史、串行自动保存与冲突处理。
- `use-app-preferences.ts`：主题、全局字体、圆角、Typeset、默认编辑模式与拼写检查的本地持久化和样式副作用。
- `typeset-preferences.ts`：精选 Markdown 字体目录及其运行时值守卫、节奏范围、参考/随机预设、旧偏好迁移与 CSS 变量映射。
- `typeset-preferences.test.ts`：参考/随机预设、自定义值、旧设置迁移和 CSS 变量回归测试。
- `use-ai-models.ts`：订阅供应商配置变更、只把已启用 Chat 模型及其连接地址暴露给任务页，以最后一次请求为准协调轻量重读和主动模型发现，并保存发现结果。
- `use-ai-models.test.ts`：任务页供应商、密钥与模型启用筛选规则的单元测试。
- `use-tasks.ts`：管理可选工作区的统一任务会话；独立草稿自动使用 Chat、工作区草稿自动使用 Agent，并持久化创作模式、跨工作区最近任务、首次发送懒创建、重命名/删除和版本化消息 Part。

## 触发器

Hook 成员、领域状态或副作用边界变化时更新本文。
