# hooks

## 地位

渲染层跨组件状态与副作用的组合入口。

## 逻辑

将预加载层能力组织成稳定的 React 状态和操作，统一协调编辑器 flush、串行保存与窗口关闭确认，页面组件只消费领域状态。

## 约束

- 不直接导入 Electron 或 Node.js 模块。
- 异步工作区切换必须拒绝过期结果。
- 文件正文不写入渲染层持久化存储。

## 成员清单

- `use-workspace.ts`：工作区恢复、文件监听、文档历史、编辑器 flush、串行自动保存、关闭确认、重命名与冲突处理。
- `use-app-preferences.ts`：主题、全局字体、圆角、正文排版、默认编辑模式与拼写检查的本地持久化和样式副作用。

## 触发器

Hook 成员、领域状态或副作用边界变化时更新本文。
