# renderer/src

## 地位

桌面应用的 React 界面入口。

## 逻辑

`main.tsx` 挂载 `App`，`app.tsx` 组合产品区域与共享 UI，`styles.css` 提供当前原型样式。

## 约束

- 文件使用小写 kebab-case，组件在代码中使用 PascalCase。
- 通用交互组件从 `@tessera/ui` 导入。
- 这里不直接导入 Base UI 或平台专有模块。

## 成员清单

- `main.tsx`：React 挂载入口。
- `app.tsx`：当前应用壳层。
- `styles.css`：应用原型样式。
- `env.d.ts`：渲染层环境类型声明。

## 触发器

入口文件、顶层界面结构、成员文件或 UI 依赖边界变化时更新本文。
