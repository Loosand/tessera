# renderer/src

## 地位

桌面应用的 React 界面入口。

## 逻辑

`main.tsx` 挂载 `App`，`app.tsx` 加载应用信息并进入产品壳层，`components/` 组合工作区界面，`hooks/` 管理领域状态，`styles.css` 加载共享 Tailwind 和阅读样式。

## 约束

- 文件使用小写 kebab-case，组件在代码中使用 PascalCase。
- 通用交互组件从 `@tessera/design-system` 的明确子路径导入。
- 这里不直接导入 Base UI 或平台专有模块。

## 成员清单

- `main.tsx`：React 挂载入口。
- `app.tsx`：渲染层根组件。
- `components/`：应用壳层、工作区侧栏与文档阅读组件。
- `hooks/`：工作区会话等跨组件状态。
- `styles.css`：设计系统样式入口与应用源码扫描声明。
- `env.d.ts`：渲染层环境类型声明。

## 触发器

入口文件、顶层界面结构、成员文件或 UI 依赖边界变化时更新本文。
