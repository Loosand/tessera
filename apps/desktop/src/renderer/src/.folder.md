# renderer/src

## 地位

桌面应用的 React 界面入口。

## 逻辑

`main.tsx` 默认挂载 `App`，只在显式查询参数下动态进入隔离的编辑器基准；`app.tsx` 加载应用信息、Motion 运行时并进入产品壳层，`motion.ts` 定义共享动效语义，`components/` 组合工作区界面，`hooks/` 管理领域状态，`styles.css` 加载共享 Tailwind、扫描应用与 `@tessera/ai/react` 源码，并统一即时编辑、静态预览与源码表面的内容排版。

## 约束

- 文件使用小写 kebab-case，组件在代码中使用 PascalCase。
- 通用交互组件从 `@tessera/design-system` 的明确子路径导入。
- 这里不直接导入 Base UI 或平台专有模块。

## 成员清单

- `main.tsx`：产品 React 挂载与按查询参数动态加载基准的入口。
- `app.tsx`：加载应用信息、按需 Motion 特性和系统减少动态效果策略的渲染层根组件。
- `motion.ts`：应用壳层、面板与微交互共享的 Motion spring 参数。
- `benchmarks/`：生产渲染进程内的编辑器性能语料与采集器。
- `components/`：应用壳层、工作区侧栏与文档阅读组件。
- `hooks/`：工作区会话等跨组件状态。
- `styles.css`：设计系统样式入口、应用及 AI package 源码扫描声明与 Markdown 内容排版基线。
- `env.d.ts`：渲染层环境类型声明。

## 触发器

入口文件、顶层界面结构、成员文件或 UI 依赖边界变化时更新本文。
