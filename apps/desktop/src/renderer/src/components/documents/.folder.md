# components/documents

## 地位

桌面渲染层的文档工作区与编辑表面目录。

## 逻辑

`DocumentHeader` 管理文档级操作与编辑模式，`DocumentEditor` 保活当前文档并在富文本/源码模式间切换，具体编辑器协议下沉到 `editor/`。

## 约束

- Markdown 是正文事实源，模式切换不得损坏未保存内容。
- 文档保存、历史和文件操作继续由工作区 Hook 与桌面契约负责。
- 编辑器内部实现不泄露到其他产品领域，跨域只消费稳定入口。

## 成员清单

- `document-header.tsx`、`document-header.test.tsx`：文档操作 Header 及静态回归测试。
- `document-editor.tsx`：保活富文本与按需源码编辑表面。
- `editor/`：TipTap、CodeMirror、Markdown 转换、粘贴和区块交互实现。

## 触发器

文档工作区、编辑模式边界、编辑器入口或成员变化时更新本文。
