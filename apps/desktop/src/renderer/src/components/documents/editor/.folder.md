# components/documents/editor

## 地位

文档编辑器的富文本集成与格式控制边界。

## 逻辑

先根据字符数、近似块密度与无法保真往返的 Markdown 语法决定是否保持 CodeMirror 源码模式；其余文本转换为 TipTap 文档，合并连续编辑且避开 IME composition 后向上发送带文档身份的 Markdown 草稿。单一浮动 chrome 提供顶层区块连续选择、键盘导航、范围操作和复用当前序列化器的系统剪贴板输出；安全 Markdown 粘贴解析为现有 schema，保存、关闭和冲突处理仍由工作区会话负责。

## 约束

- Markdown 始终是持久化事实源。
- 扩展列表集中维护，业务组件不得临时拼装不同 schema。
- 编辑器交易不直接调用 Electron 或文件系统 API。
- 文件名使用小写 kebab-case。

## 成员清单

- `editor-extensions.ts`：TipTap 扩展、表格 schema、Markdown 解析配置和同配置 manager 工厂。
- `editor-content-sync.ts`：支持 IME 暂停/恢复的延迟草稿同步、强制提交和取消控制器。
- `editor-content-sync.test.ts`：延迟合并、中文 IME、文档身份和强制提交测试。
- `editor-interactions.test.ts`：编辑快捷键与中文输入撤销/重做测试。
- `editor-mode-policy.ts`：富文本字符数、近似块密度与源码优先语法保护策略。
- `editor-mode-policy.test.ts`：性能及兼容性保护边界测试。
- `editor-shortcuts.ts`：保存、模式切换与编辑表面原生按键的快捷键仲裁。
- `markdown-compatibility.ts`：忽略代码样例后识别 HTML、脚注和定义式链接等源码优先语法。
- `markdown-compatibility.test.ts`：嵌套列表、复杂表格与源码优先语法的兼容性语料。
- `markdown-clipboard.ts`：把连续顶层区块按现有规则序列化为 Markdown，并封装可测试的剪贴板写入状态。
- `markdown-clipboard.test.ts`：跨块序列化、剪贴板快捷键与失败安全测试。
- `markdown-paste.ts`：识别安全 Markdown 剪贴板文本，并生成结构化 ProseMirror 粘贴 transaction。
- `markdown-paste.test.ts`：结构识别、富内容优先与块级粘贴测试。
- `markdown-document.ts`：YAML frontmatter 与正文的拆分、重组。
- `markdown-document.test.ts`：frontmatter 与 Markdown 结构的往返测试。
- `markdown-table.ts`：保证单元格管道符、行内代码和对齐稳定往返的 GFM 表格序列化适配。
- `rich-text-editor.tsx`：Typeset 排版的 TipTap 保活生命周期、结构化 Markdown 粘贴、区块 chrome、延迟同步和 flush 注册。
- `source-code-editor.tsx`：按需加载后的 CodeMirror 6 生命周期、Markdown 高亮、IME 安全同步、主题、会话恢复和跳行处理。
- `source-code-editor-state.ts`：CodeMirror 选区/滚动快照边界、跳行事件守卫与跨组件源码跳行协议。
- `source-code-editor-state.test.ts`：源码会话边界、一基准跳行与延迟加载请求回归测试。
- `slash-command-menu.tsx`：光标斜杠查询、键盘导航和高密度分组命令呈现。
- `top-level-block-handle.tsx`：共享的顶层区块手柄、连续多选、Markdown 复制/剪切、键盘导航、可检索操作菜单、拖动目标线和逐帧 hover 定位。
- `top-level-block-operations.ts`：不依赖 DOM 的顶层区块、连续范围定位与 transaction 变换。
- `top-level-block-operations.test.ts`：相邻导航、连续范围复制、删除、移动、转换和 Markdown schema 回归测试。

## 触发器

编辑能力、扩展 schema、Markdown 往返规则或成员变化时更新本文。
