# components/settings

## 地位

桌面渲染层的统一设置导航与设置领域页面。

## 逻辑

`SettingsPage` 维护分类导航和搜索，分别组合外观、编辑器、快捷键、AI 与 MCP 设置；Typeset 构建器作为编辑器设置中的实时预览工具。

## 约束

- 新输入的秘密只短暂保留在组件内存，持久化后只展示配置状态。
- 设置页只调用注入的类型化桌面能力，不直接访问 Electron 或存储。
- 通用表单、浮层与选择控件来自设计系统。

## 成员清单

- `settings-page.tsx`：设置分类、搜索与领域页面装配。
- `appearance-settings.tsx`：主题、字体、形状与自定义主题入口。
- `editor-settings.tsx`：Markdown 主题、编辑行为与呈现设置。
- `typeset-theme-builder.tsx`：字体、阅读节奏和版心的实时预览构建器。
- `shortcuts-settings.tsx`：命令分组、默认绑定与可用状态。
- `mcp-settings.tsx`：MCP 连接、秘密、信任与工具开关管理。
- `ai-settings.test.tsx`：AI 研究网络设置的静态回归测试。

## 触发器

设置分类、配置边界、设置组件或成员变化时更新本文。
