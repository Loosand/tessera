# components/app

## 地位

桌面渲染层的顶层产品装配目录。

## 逻辑

`AppShell` 消费应用 Hook 状态并组合一级视图；`HomeSidebar` 提供 Space、任务与设置导航，`AgentSidebar` 在文档旁复用任务会话。下层领域不反向依赖本目录。

## 约束

- 只在本目录协调跨领域可见性、布局和保活策略，不承载领域数据实现。
- 平台读写继续通过 Hook 与桌面契约完成。
- 侧栏与主区共享会话时保持单一任务事实源。

## 成员清单

- `app-shell.tsx`：顶层布局、一级视图、任务/文档保活和跨 Space 恢复。
- `app-shell.test.ts`：顶层任务选择状态的纯函数回归测试。
- `home-sidebar.tsx`：Space 内任务、Skill、文件树与全局设置入口。
- `agent-sidebar.tsx`：文档右侧可调宽的同源任务会话面板。
- `agent-sidebar.test.tsx`：侧栏 Header、宽度边界和可访问调宽行为测试。

## 触发器

顶层布局、一级导航、跨领域装配或成员变化时更新本文。
