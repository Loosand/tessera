# components/chat-parts

## 地位

普通对话消息内部按 AI SDK Part 类型拆分的呈现层。

## 逻辑

协调组件按消息中的原始 Part 顺序渲染正文和工具状态，来源单独汇总去重；每个组件只解释自己的流式状态，不合并或改写 Transport 事件。

## 约束

- 保留 `UIMessage.parts` 的边界与顺序，不把多个正文 Part 拼成一个不可区分的字符串。
- 增量中的正文与工具必须提供明确的 `aria-busy` 状态。
- Markdown 渲染、来源标签和工具状态不访问 Electron 或业务存储。

## 成员清单

- `text-part.tsx`：逐个渲染 Markdown 正文 Part，并标记正在生成的末尾光标。
- `source-part.tsx`：汇总、去重并呈现 URL 与文档来源。
- `tool-part.tsx`：呈现动态或具名工具 Part 的输入、执行、完成与错误状态。

## 触发器

AI SDK Part 类型、流式状态或成员变化时更新本文。
