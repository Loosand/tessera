# components/workspace

## 地位

桌面渲染层的 Space 选择、工作区文件树与对象命令目录。

## 逻辑

Space 切换器选择默认空间或文件工作区；文件树模型先合并、排序并派生层级，再由文件区呈现；工作区和条目菜单把用户命令转交给上层 Hook。

## 约束

- 不直接访问文件系统、Electron 或数据库。
- 文件树排序、层级和空目录行为保持在纯模型中可测试。
- 所有路径命令只传递桌面契约允许的工作区相对路径。

## 成员清单

- `space-switcher.tsx`：默认空间与最近文件工作区切换菜单。
- `space-files-section.tsx`：可滚动文件树及条目上下文入口。
- `space-files-model.ts`、`space-files-model.test.ts`：文件树合并、排序、层级派生及测试。
- `workspace-context-menu.tsx`：最近工作区对象命令。
- `workspace-entry-context-menu.tsx`：工作区文件与文件夹对象命令。

## 触发器

Space 选择、文件树模型、工作区命令或成员变化时更新本文。
