# components/skills

## 地位

桌面渲染层的用户 Skill 管理产品页面。

## 逻辑

管理页消费用户 Skill Hook，呈现受限目录导入、递归扫描预览、安装、搜索、详情、启停与删除，并允许从已启用 Skill 创建任务。

## 约束

- 目录扫描与导入必须由主进程受限能力完成。
- 页面不执行 Skill 脚本，不把 Skill 说明解释为额外权限。
- 权限和加载机制保持按需说明，避免与常用管理操作混排。

## 成员清单

- `skill-management-page.tsx`：用户 Skill 导入、扫描、管理与任务入口。
- `skill-management-page.test.tsx`：注册表、导入入口和按需详情的静态回归测试。

## 触发器

Skill 管理流程、权限说明或成员变化时更新本文。
