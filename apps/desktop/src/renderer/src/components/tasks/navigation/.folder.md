# components/tasks/navigation

## 地位

任务浏览、分页、共享导航行与任务对象命令目录。

## 逻辑

全部任务页消费服务端分页读取器，导航行在全局/工作区/文档侧栏复用统一选中与运行状态；行尾操作和上下文菜单把置顶、归档、恢复、重命名与删除命令交给上层任务状态。

## 约束

- 活动与归档列表使用服务端稳定分页，不在组件内复制全量数据。
- 置顶、归档与运行状态不得改变标题可用宽度或破坏键盘访问。
- 删除和重命名继续经过主进程契约与确认边界。

## 成员清单

- `all-tasks-page.tsx`：活动/归档任务分页浏览页。
- `task-pagination-controls.tsx`、`task-pagination-controls.test.tsx`：分页控件及首尾边界测试。
- `task-navigation-row.tsx`、`task-navigation-row.test.tsx`：共享任务导航行及状态语义测试。
- `task-row-actions.tsx`、`task-row-actions.test.tsx`：置顶、归档与恢复行尾命令及测试。
- `task-context-menu.tsx`：打开、重命名和删除任务的上下文命令。

## 触发器

任务分页、导航模式、对象命令或成员变化时更新本文。
