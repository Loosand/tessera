# components/tasks/artifacts

## 地位

任务正式产物的消息内呈现与文档协作入口目录。

## 逻辑

产物托盘只呈现已持久化 Artifact，把托管项目文档交给应用壳打开为文档主区，并在右侧继续同一任务会话。

## 约束

- 临时工具输出不伪装成正式 Artifact。
- 打开产物不创建第二条任务会话。
- 文件与项目身份以主进程返回的稳定引用为准。

## 成员清单

- `task-artifact-tray.tsx`：正式产物呈现和文档打开入口。
- `task-artifact-tray.test.tsx`：标题、项目归属和打开入口的静态测试。

## 触发器

Artifact 呈现、打开协作流程或成员变化时更新本文。
