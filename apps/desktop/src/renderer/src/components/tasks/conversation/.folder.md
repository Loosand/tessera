# components/tasks/conversation

## 地位

统一任务会话页面与逐轮输入选择目录。

## 逻辑

`TaskPage` 连接应用级模型快照、持久化任务恢复和消息呈现；`TaskComposer` 收集正文、附件、Skill 与模型选择，模型和能力选择器只负责本轮输入，不自行提交运行策略。

## 约束

- 主任务与文档 Agent 侧栏复用同一 `TaskPage`。
- 当前运行冻结已提交的选择，新选择只影响后续运行。
- Composer 不暴露受信任 RunPolicy 的内部能力开关。

## 成员清单

- `task-page.tsx`、`task-page.test.ts`：统一会话页面及策略/恢复回归测试。
- `task-composer.tsx`、`task-composer.test.tsx`：输入、附件、上下文与逐轮选择表面及测试。
- `task-capability-picker.tsx`：自动编排、Skill 与问答预设选择。
- `model-picker.tsx`：按供应商分组的模型选择器。

## 触发器

任务会话、Composer、模型/能力选择或成员变化时更新本文。
