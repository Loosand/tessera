# components/tasks/messages

## 地位

任务消息协调、流式 Part 呈现与单次运行检查目录。

## 逻辑

`ChatMessage` 保留原始 Part 顺序，识别正式回答边界并把自动过程聚合为“已工作”；具体消息 Part 下沉到 `chat-parts/`，运行检查通过窄 IPC 按需读取脱敏指标和策略事实。

## 约束

- 展示层不重排、拼接或伪造供应商未返回的消息内容。
- 人工审批、等待输入、失败和正式产物不得隐藏进自动过程折叠区。
- 运行检查只呈现已上报或可推导的脱敏事实，缺失值不伪造为零。

## 成员清单

- `chat-message.tsx`、`chat-message.test.tsx`：消息 Part 协调、正式回答边界与回归测试。
- `chat-parts/`：按 AI SDK Part 类型拆分的流式呈现单元。
- `run-inspection-popover.tsx`、`run-inspection-popover.test.tsx`：Token、策略、资源、耗时与错误检查及测试。

## 触发器

消息协调、Part 边界、运行检查或成员变化时更新本文。
