# components/tasks

## 地位

桌面渲染层的任务领域索引；本层只保留会话、消息、导航与产物职责目录。

## 逻辑

`conversation/` 持有统一任务页面和逐轮输入，`messages/` 呈现有序流式消息与运行检查，`navigation/` 管理任务浏览及对象命令，`artifacts/` 把正式产物接回文档协作视图。

## 约束

- 完整 `UIMessage.parts` 顺序与任务持久化边界不得在展示层改写。
- 主任务与文档侧栏复用同一会话实现，不复制运行状态机。
- 子目录之间通过明确组件契约协作，不以循环导入共享内部状态。
- 平台操作必须沿用主进程契约，不直接访问 Electron 或存储。

## 成员清单

- `conversation/`：统一任务页、Composer、模型与能力选择。
- `messages/`：消息协调、流式 Part 与运行检查。
- `navigation/`：全部任务页、分页、导航行和任务对象命令。
- `artifacts/`：正式产物呈现与文档打开入口。

## 触发器

任务子领域、依赖方向或目录职责发生变化时更新本文。
