# components/editor

## 地位

文档编辑器的富文本集成与格式控制边界。

## 逻辑

将 Markdown 文本转换为 TipTap 文档，向上只发送新的 Markdown 草稿；文件保存和冲突处理仍由工作区会话负责。

## 约束

- Markdown 始终是持久化事实源。
- 扩展列表集中维护，业务组件不得临时拼装不同 schema。
- 编辑器交易不直接调用 Electron 或文件系统 API。
- 文件名使用小写 kebab-case。

## 成员清单

- `editor-extensions.ts`：TipTap 扩展、表格 schema 和 Markdown 解析配置。
- `editor-toolbar.tsx`：格式命令、激活状态、链接及表格浮层。
- `markdown-document.ts`：YAML frontmatter 与正文的拆分、重组。
- `markdown-document.test.ts`：frontmatter 与 Markdown 结构的往返测试。
- `rich-text-editor.tsx`：TipTap 生命周期和 Markdown 双向同步。
- `slash-command-menu.tsx`：光标斜杠查询、键盘导航和块级命令呈现。

## 触发器

编辑能力、扩展 schema、Markdown 往返规则或成员变化时更新本文。
