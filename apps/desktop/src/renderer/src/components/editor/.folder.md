# components/editor

## 地位

文档编辑器的富文本集成与格式控制边界。

## 逻辑

将 Markdown 文本转换为 TipTap 文档，合并连续编辑后向上发送带文档身份的 Markdown 草稿；单一浮动 chrome 提供顶层区块选择与操作，保存、关闭和冲突处理仍由工作区会话负责。

## 约束

- Markdown 始终是持久化事实源。
- 扩展列表集中维护，业务组件不得临时拼装不同 schema。
- 编辑器交易不直接调用 Electron 或文件系统 API。
- 文件名使用小写 kebab-case。

## 成员清单

- `editor-extensions.ts`：TipTap 扩展、表格 schema 和 Markdown 解析配置。
- `editor-content-sync.ts`：延迟草稿同步、强制提交和取消控制器。
- `editor-content-sync.test.ts`：延迟合并、文档身份和强制提交测试。
- `editor-mode-policy.ts`：富文本大文档保护阈值。
- `editor-mode-policy.test.ts`：大文档保护边界测试。
- `editor-toolbar.tsx`：带可访问 Motion 进场的格式命令、激活状态、链接及表格浮层。
- `markdown-document.ts`：YAML frontmatter 与正文的拆分、重组。
- `markdown-document.test.ts`：frontmatter 与 Markdown 结构的往返测试。
- `rich-text-editor.tsx`：TipTap 保活生命周期、区块 chrome、延迟 Markdown 同步和 flush 注册。
- `slash-command-menu.tsx`：光标斜杠查询、键盘导航和高密度分组命令呈现。
- `top-level-block-handle.tsx`：共享的顶层区块手柄、可检索操作菜单、拖动目标线和逐帧 hover 定位。
- `top-level-block-operations.ts`：不依赖 DOM 的顶层区块定位与 transaction 变换。
- `top-level-block-operations.test.ts`：区块复制、删除、移动、转换和 Markdown schema 回归测试。

## 触发器

编辑能力、扩展 schema、Markdown 往返规则或成员变化时更新本文。
