# components

## 地位

桌面渲染层的产品组件领域索引；本层只保留职责目录，不再平铺具体组件。

## 逻辑

`app/` 负责顶层装配，向下组合任务、工作区、文档、设置与 Skill 领域；各领域内部维护自己的页面、局部模型和交互部件，流式消息与编辑器实现继续下沉到更窄的子目录。

## 约束

- 通用交互原语来自 `@tessera/design-system`。
- 平台能力只通过 Hook 和宿主无关桌面契约使用。
- 领域组件不得反向依赖 `app/`；跨领域组合优先留在 `app/`。
- 新组件先归入现有职责目录，只有形成独立边界时才新增同级目录与 `.folder.md`。

## 成员清单

- `app/`：应用壳层、一级侧栏与文档 Agent 侧栏。
- `tasks/`：任务页面、会话输入、消息、导航、Artifact 与运行检查。
- `workspace/`：Space 切换、文件树与工作区对象命令。
- `documents/`：文档 Header、编辑表面与编辑器实现。
- `settings/`：设置导航及各设置领域页面。
- `skills/`：用户 Skill 管理页面。

## 触发器

一级组件领域、依赖方向或目录职责发生变化时更新本文。
