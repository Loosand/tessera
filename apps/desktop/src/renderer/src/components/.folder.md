# components

## 地位

桌面渲染层的产品级组合组件。

## 逻辑

组合首页、Skill 管理、任务入口、工作区、侧栏导航、文档顶栏、保活编辑画布和按需侧面板；Skill、任务、工作区与设置视图预先挂载并通过显隐切换，避免交互路径中的重建成本。

## 约束

- 通用交互原语来自 `@tessera/design-system`。
- 平台能力只通过 Hook 和预加载契约使用。
- 文件名使用小写 kebab-case，单个组件保持清晰职责。

## 成员清单

- `app-shell.tsx`：桌面窗口顶层布局、独立草稿/工作区任务分流、首页/Skill/任务/设置/工作区保活、跨工作区任务恢复、CodeMirror 源码行导航、平台标题栏安全区、Motion 侧栏重排、编辑模式保护与窄窗口响应。
- `home-sidebar.tsx`：一级首页与独立草稿的 Skill 导航、最近任务、最近工作区、右键命令和全局设置入口。
- `workspace-home-page.tsx`：一级工作区聚合页，展示跨工作区最近任务、最近工作区、对象右键命令、打开工作区入口和折叠态标题栏安全区。
- `skill-management-page.tsx`：内置 Skill 的搜索、卡片选择、权限与加载机制说明，以及按 Skill 创建任务的一级管理页。
- `skill-management-page.test.tsx`：管理页直接呈现内置注册表、权限边界和规划状态的静态回归验证。
- `task-page.tsx`：Chat/Agent 任务顶栏、内置 Skill 透传、历史消息与后台运行恢复、静默后台模型同步、稳定消息快照持久化与多轮流式消息布局；运行中不持久化未完成助手尾消息，避免返回页面重放时重复；Agent 校验工作区/模型能力并协调变更预览、AI SDK 审批响应与文件跳转。
- `task-composer.tsx`：可有限增高的紧凑任务输入表面，以两组原生单选分别切换问答/研究/写作 Skill 与 Chat/Agent 执行模式，并在任务落库后锁定选择；模型、只读范围、附件和操作失败反馈保持在底部工具栏。
- `model-picker.tsx`：按供应商分组并呈现模型头像、能力摘要与选中态的任务模型浮层。
- `chat-message.tsx`：用户消息与助手消息 Part 的顺序协调，以消息内位置生成稳定唯一键，并组织思考、工具审批、文件引用和重试操作。
- `chat-message.test.tsx`：验证多 Agent 步骤复用 provider reasoning ID 时不会产生 React key 冲突。
- `chat-parts/`：思考、正文、来源和工具调用的独立流式呈现单元。
- `document-header.tsx`：文档历史、文件信息、保存状态与详情工具入口。
- `agent-sidebar.tsx`：当前文档的 AI 协作面板及其可访问进退场边界。
- `workspace-sidebar.tsx`：二级工作区侧栏，负责返回主页、切换工作区、任务/文件切换、任务列表与右键命令、真实目录文件树、文档列表、大纲和工作区菜单。
- `task-context-menu.tsx`：对话的打开、重命名和确认删除命令，以及无聚焦装饰的重命名对话框。
- `workspace-context-menu.tsx`：最近工作区的打开、Finder 定位、路径复制和可恢复移除命令。
- `workspace-entry-context-menu.tsx`：文件/文件夹的新建、重命名、复制路径、Finder 定位与废纸篓命令菜单。
- `workspace-sidebar-model.ts`：侧栏排序、真实目录/文档文件树和 Markdown 大纲派生模型。
- `workspace-sidebar-model.test.ts`：侧栏模型单元测试。
- `settings-page.tsx`：设置分类搜索、Markdown 主题宽幅画布、AI/模型供应商独立导航，以及类型化供应商配置读写/删除、变更订阅和模型发现函数注入。
- `appearance-settings.tsx`：主题、全局字体、形状与自定义主题预留入口。
- `editor-settings.tsx`：Markdown 主题参考预设、随机搭配、编辑行为、编辑器呈现与规划能力状态。
- `typeset-theme-builder.tsx`：精选标题/正文/等宽字体、阅读节奏、版心控制与真实 Typeset 实时预览。
- `shortcuts-settings.tsx`：可搜索的中文命令分组、默认绑定与可用状态。
- `document-editor.tsx`：保活即时预览、按需加载并保活当前文档 CodeMirror 源码表面，以及性能、Markdown 保真保护的文档工作区。
- `editor/`：TipTap 集成、Markdown 转换、斜杠命令和区块交互。

## 触发器

组件成员、职责或组合关系变化时更新本文。
