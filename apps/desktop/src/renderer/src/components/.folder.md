# components

## 地位

桌面渲染层的产品级组合组件。

## 逻辑

以工作区为边界组合窗口壳层、侧栏导航、文档顶栏、编辑画布和按需侧面板。

## 约束

- 通用交互原语来自 `@tessera/design-system`。
- 平台能力只通过 Hook 和预加载契约使用。
- 文件名使用小写 kebab-case，单个组件保持清晰职责。

## 成员清单

- `app-shell.tsx`：桌面窗口顶层布局、窄窗口响应与侧栏显隐协调。
- `document-header.tsx`：文档历史、文件信息、保存状态与详情工具入口。
- `agent-sidebar.tsx`：当前文档的 AI 协作面板边界。
- `workspace-sidebar.tsx`：文件树、文档列表、大纲和工作区菜单。
- `workspace-sidebar-model.ts`：侧栏排序、文件树和 Markdown 大纲派生模型。
- `workspace-sidebar-model.test.ts`：侧栏模型单元测试。
- `settings-page.tsx`：设置分类导航、偏好控件与工作区返回入口。
- `document-editor.tsx`：即时预览编辑与 Markdown 源码的文档工作区。
- `editor/`：TipTap 集成、Markdown 转换和格式工具栏。

## 触发器

组件成员、职责或组合关系变化时更新本文。
