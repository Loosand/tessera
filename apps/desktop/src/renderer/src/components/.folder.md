# components

## 地位

桌面渲染层的产品级组合组件。

## 逻辑

组合 Space 落地页、Skill 管理、任务入口、工作区、侧栏导航、文档顶栏、保活编辑画布和按需侧面板；Skill、任务、工作区与设置视图预先挂载并通过显隐切换，避免交互路径中的重建成本。

## 约束

- 通用交互原语来自 `@tessera/design-system`。
- 平台能力只通过 Hook 和预加载契约使用。
- 文件名使用小写 kebab-case，单个组件保持清晰职责。

## 成员清单

- `app-shell.tsx`：桌面窗口顶层布局、默认空间/文件工作区作用域选择、新任务与历史任务互斥选中、分页任务与文件树共存的内嵌侧栏、全部任务一级页面、主任务与独立可调宽文档对话侧栏共用会话、Space 落地页/Skill/任务/设置/编辑器保活、跨空间任务恢复、CodeMirror 源码行导航、Motion 侧栏重排、编辑模式保护与窄窗口响应。
- `app-shell.test.ts`：新任务草稿、历史任务与文档 AI 侧栏任务互斥选中状态的纯函数回归测试。
- `home-sidebar.tsx`：当前 Space 的新任务/全部任务/Skill 导航、可翻页作用域最近任务、文件树区块、右键命令和全局设置入口。
- `all-tasks-page.tsx`：当前 Space 的全量任务浏览一级页面，按最后对话更新时间稳定排序并提供分页、打开、重命名和删除。
- `task-pagination-controls.tsx`：侧栏与全部任务页共享的上一页/下一页、页码和总数控件。
- `task-pagination-controls.test.tsx`：任务分页总数、页码和首尾禁用语义的静态回归测试。
- `space-switcher.tsx`：侧栏顶部固定包含默认空间与最近文件工作区、支持文件 Space 对象命令的紧凑切换菜单。
- `space-files-section.tsx`：一级 Space 侧栏内带叶节点自然缩进和右侧标题安全区的真实目录/Markdown 文件树，以及新建、刷新和条目上下文操作。
- `space-files-model.ts`：一级侧栏文件树合并、排序、自然层级缩进和可展开目录路径派生模型。
- `space-files-model.test.ts`：文件夹优先排序、自然层级缩进、空目录保留和目录路径收集的单元测试。
- `skill-management-page.tsx`：内置/用户 Skill 的单目录导入、递归扫描结果预览与勾选批量安装、搜索、卡片选择、启停、删除、权限/加载机制说明，以及按 Skill 创建任务的一级管理页。
- `skill-management-page.test.tsx`：管理页直接呈现内置注册表、用户单目录导入/扫描入口、权限与脚本不执行边界的静态回归验证。
- `task-page.tsx`：主任务页与文档侧栏共用的统一 Agent 会话实现；空任务时作为当前 Space 落地页展示空间标识、Composer 和作用域最近任务，运行后以一致阅读栏组织整行用户消息、连续助手正文、过程对象与随消息滚动的 Artifact，并在整轮运行期间于消息流末尾常驻“正在处理”计时；切换历史任务时先无副作用恢复消息并在首帧定位到最新内容；侧栏空态不重复解释文档上下文，只保留独立消息画布与固定底部输入表面；消费应用级 SQLite 模型快照并恢复任务/默认模型选择，使用与主进程同源的 RunPolicy 解析器做发送前预检但不提交能力开关，把当前 Markdown 草稿作为显式附件发送，并协调已持久化任务恢复、本地赞踩、研究笔记/来源材料、Artifact、结构化问答、Diff 审批与文件跳转。
- `task-artifact-tray.tsx`：在消息流中展示当前任务正式产物，并把托管项目文档打开为文档主区加同一会话侧栏的协作视图。
- `task-artifact-tray.test.tsx`：正式产物标题、所属项目和打开入口的静态呈现测试。
- `task-page.test.ts`：研究强制深度思考与原生联网、问答离线、自动回落、历史恢复不误保存及助手反馈写入/撤销的回归测试。
- `task-composer.tsx`：可有限增高、以单一静态外轮廓包裹白色正文操作面与高对比浅灰底栏的任务输入表面，常驻附件、上下文与权限浮层、逐轮创作方式、模型与发送入口；当前文档和图片通过同一附件浮层添加，运行时选择、权限范围长文与专业能力开关不进入常驻 UI。
- `task-composer.test.tsx`：输入框不暴露 Chat/Agent、联网、思考开关和权限范围长文，保留范围浮层入口与真实错误直显，锁定单一静态轮廓及底栏选择器的小字号胶囊入口，并区分模型加载/未配置状态的静态回归验证。
- `agent-sidebar.tsx`：与文档列并列、拥有独立精简 Header 的右侧对话面板；默认 460px，支持鼠标/键盘调宽、380–720px 响应式边界和版本化本地宽度记忆，并承载与主任务同源的 TaskPage。
- `agent-sidebar.test.tsx`：侧栏独立 Header、无重复任务控件、可访问调宽分隔条和响应式宽度边界的回归测试。
- `task-capability-picker.tsx`：以闪光、搜索、编辑和对话等直接语义图标及双行说明呈现自动编排、内置/已启用用户 Skill 与问答预设；当前运行保持冻结策略，新选择从之后发起的运行生效。
- `model-picker.tsx`：以次级小字号胶囊入口和统一的菜单/选中项圆角层级，按供应商分组呈现模型头像、当前连接上的有效能力摘要、加载状态与选中态。
- `chat-message.tsx`：用户消息与助手消息 Part 的顺序协调，以最后一次信息性自动执行划分正式回答，把此前 reasoning、过程说明、搜索、研究计划和自动工具组织进统一“已工作”区块，同时把问答、审批、失败、产物与正式回答保留在外，并协调回答后引申问题、复制、本地赞踩、运行解释和重试。
- `chat-message.test.tsx`：验证多 Agent 步骤复用 provider reasoning ID 时不会产生 React key 冲突、正式回答边界与工作过程完成折叠，并呈现研究笔记入口、来源推荐、回答后引申问题与已保存赞踩状态。
- `run-inspection-popover.tsx`：通过消息操作栏图标按需展示实际模型、Skill、资源、工具及结束/失败原因，不把开发日志或权限长文铺在对话正文中。
- `run-inspection-popover.test.tsx`：运行状态、Skill 与工具异常摘要的纯展示回归测试。
- `chat-parts/`：思考、正文、来源、结构化人机交互和工具调用的独立流式呈现单元。
- `document-header.tsx`：文档历史、文件信息、保存状态、编辑模式和侧边对话开关；设置入口留在一级 Space 侧栏，不与文档操作混排。
- `document-header.test.tsx`：文档 Header 只保留右栏图形开关、不重复设置入口及打开/关闭可访问文案的静态回归验证。
- `task-navigation-row.tsx`：全局、工作区与文档 AI 侧栏共享的任务导航行，统一较浅 hover、明确选中背景与可访问运行中 loader。
- `task-navigation-row.test.tsx`：选中任务语义和运行中/完成态 loader 的静态回归验证。
- `task-context-menu.tsx`：对话的打开、重命名和确认删除命令，以及无聚焦装饰的重命名对话框。
- `workspace-context-menu.tsx`：最近工作区的打开、Finder 定位、路径复制和可恢复移除命令。
- `workspace-entry-context-menu.tsx`：文件/文件夹的新建、重命名、复制路径、Finder 定位与废纸篓命令菜单。
- `settings-page.tsx`：设置分类搜索、常规设置统一宽度、Markdown 主题画布、AI/模型供应商/MCP 独立导航、研究网络偏好与仅开发环境 AI SDK 日志的类型化安全桥函数注入。
- `ai-settings.test.tsx`：验证研究网页系统代理/直连选项及“只影响后续任务”的可见说明。
- `mcp-settings.tsx`：MCP 服务器目录/详情、连接与加密变量编辑、显式信任、检测握手、逐工具开关和删除确认。
- `appearance-settings.tsx`：主题、全局字体、形状与自定义主题预留入口。
- `editor-settings.tsx`：Markdown 主题参考预设、随机搭配、编辑行为、编辑器呈现与规划能力状态。
- `typeset-theme-builder.tsx`：精选标题/正文/等宽字体、阅读节奏、版心控制与真实 Typeset 实时预览。
- `shortcuts-settings.tsx`：可搜索的中文命令分组、默认绑定与可用状态。
- `document-editor.tsx`：保活即时预览、按需加载并保活当前文档 CodeMirror 源码表面，以及性能、Markdown 保真保护的文档工作区。
- `editor/`：TipTap 集成、Markdown 转换、斜杠命令和区块交互。
