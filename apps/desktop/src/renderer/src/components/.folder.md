# components

## 地位

桌面渲染层的产品级组合组件。

## 逻辑

组合任务入口、工作区、侧栏导航、文档顶栏、保活编辑画布和按需侧面板；任务、工作区与设置视图预先挂载并通过显隐切换，避免交互路径中的重建成本。

## 约束

- 通用交互原语来自 `@tessera/design-system`。
- 平台能力只通过 Hook 和预加载契约使用。
- 文件名使用小写 kebab-case，单个组件保持清晰职责。

## 成员清单

- `app-shell.tsx`：桌面窗口顶层布局、任务/设置/工作区保活、平台标题栏安全区、Motion 侧栏重排、编辑模式保护与窄窗口响应。
- `task-page.tsx`：新任务顶栏、居中任务输入框与运行时接入前的交互反馈。
- `document-header.tsx`：文档历史、文件信息、保存状态与详情工具入口。
- `agent-sidebar.tsx`：当前文档的 AI 协作面板及其可访问进退场边界。
- `workspace-sidebar.tsx`：新任务入口、文件树、文档列表、大纲和工作区菜单。
- `workspace-sidebar-model.ts`：侧栏排序、文件树和 Markdown 大纲派生模型。
- `workspace-sidebar-model.test.ts`：侧栏模型单元测试。
- `settings-page.tsx`：设置分类搜索、AI/模型供应商独立导航，以及类型化供应商配置读写/删除、变更订阅和模型发现函数注入。
- `appearance-settings.tsx`：主题、全局字体、形状与自定义主题预留入口。
- `editor-settings.tsx`：正文排版、编辑行为、编辑器呈现与规划能力状态。
- `shortcuts-settings.tsx`：可搜索的中文命令分组、默认绑定与可用状态。
- `document-editor.tsx`：保活即时预览/Markdown 源码表面以及大文档保护的文档工作区。
- `editor/`：TipTap 集成、Markdown 转换和格式工具栏。

## 触发器

组件成员、职责或组合关系变化时更新本文。
