# main

## 地位

Electron 主进程入口，持有窗口生命周期与平台能力。

## 逻辑

启动时打开本地数据库，组装 AI 配置、任务会话、混合内容库、历史研究读取、旧 Agent 变更兼容、MCP、用户 Skill
与 Electron `safeStorage`，随后注册 IPC 并创建安全窗口。工作区服务集中执行真实路径、Markdown 类型、可见目录、
版本冲突和原子保存；托管内容库保持 Markdown 为正文事实源，SQLite 只保存稳定引用、Artifact、资源关系和操作审计。

每轮由主进程根据用户文本、授权资源和模型事实生成 RunPolicy，所有任务进入共用 AI SDK `ToolLoopAgent`。当前工作区
存在且请求相关时注入 `read/edit/write`，macOS 隔离能力探针通过时增加受控 `bash`；联网时注入供应商搜索和无状态受限 Web Reader；
内容库和研究领域工具不再进入新运行，MCP 仍按独立信任与逐次审批注入。文件完整重写要求当前 run 读完同一版本；
修改在同文件队列内复核 hash，并在原子替换前再次检查目标版本。成功后由内容服务登记 Artifact；登记异常不能把已提交文件伪装成失败。历史研究数据、旧 Tool Part 与 Diff 只读
兼容，不重放副作用。运行策略、资源摘要、有序事件、指标和终态同步到 SQLite，页面离开或应用重启后按恢复协议重放；
异常先分类为版本化公开错误。开发期 Telemetry、用户 Skill 导入、任务/工作区管理和关闭保存握手继续由主进程持有。

模型 chunk 在入 SQLite/IPC 前经运行事件账本归一：工具终态按 `toolCallId` 去重，截断/取消的悬空
调用变为稳定错误，run terminal 之后丢弃迟到事件。任务导航命令由主进程持久化置顶/归档状态；活动列表按置顶优先，
归档列表独立分页，删除仍使用系统确认。

## 约束

- 窗口保持 `contextIsolation` 与沙箱开启，禁止 Node.js 集成。
- 新增 IPC 前先在 `@tessera/contracts` 定义契约。
- AI API Key 不得记录或进入渲染层持久化存储；数据库只保存 `safeStorage` 密文，系统安全存储不可用时拒绝保存明文。
- MCP 环境变量和请求头在加密前与历史密文解密后都必须复核下游名称/字符边界；连接/启用前必须显式信任，已启用工具仍须逐次人工批准。
- 用户 Skill 只能通过系统目录选择器导入或扫描；扫描结果只返回相对路径并由短时主进程会话绑定源目录，必须限制深度/目录数/候选数，导入时仍须拒绝符号链接/特殊文件并限制文件数量和体积；运行时只读取托管 `SKILL.md`，不执行脚本或扩大权限。
- 文件路径必须在主进程中解析并限制在当前工作区内。
- Bash 只在平台隔离探针通过时注册；必须清空宿主环境、拒绝网络与越界、限制输出，并在进程组和 stdio 收口后返回，不得回退到裸 Shell。
- 文件与目录的重命名、废纸篓、Finder 定位和路径复制只能接收已验证的工作区相对路径。
- 文档保存必须校验磁盘版本并在同目录内原子替换。
- 文档重命名必须校验文件名、保留 Markdown 扩展名并禁止覆盖已有文件。
- 每个工作区监听器随对应窗口销毁，禁止遗留后台观察器。
- 路由或组件卸载不得隐式取消生成；只有用户显式停止、任务删除、窗口销毁或应用退出可以中止主进程运行。
- 已完成运行的内存事件日志只用于短时页面恢复，必须设定释放时机与最长保留期，不替代任务消息持久化。
- 窗口关闭与应用退出必须经过请求、保存确认或取消握手，数据库只在最终退出阶段关闭。

## 成员清单

- `content-library-service.ts`：探索期托管内容库、未归档、项目、安全移动，以及直接文件提交或 Bash 文件事件后的 Document/Artifact/资源关系登记边界。
- `content-library-service.test.ts`：内容创建、项目移动与回滚、授权撤销、直接/Bash 工作区文件 Artifact 登记和跨重启恢复测试。
- `index.ts`：主进程启动、窗口配置、AI 后台运行/有序事件重放、ExecutionEnvironment 探针和 Bash Markdown Artifact 登记、已完成工具结果续跑校验、当前 Space 任务分页、工作区平台对话框与其他 IPC 注册。
- `ai-chat-error.ts`：把启动、流式、恢复和工具执行阶段的未知异常分类为带稳定 code、可选 HTTP 状态、phase/tool 标识与 retryable 的脱敏公开错误，并保留具名主进程领域错误的安全文案。
- `ai-chat-error.test.ts`：验证配置、主进程领域错误、认证、限流、网络、恢复和未知异常的分类与脱敏边界。
- `ai-devtools.ts`：仅开发环境注册 AI SDK 官方 Telemetry，按需启动/探测本地 Viewer 并在退出时清理子进程。
- `ai-chat-event.ts`：校验 SQLite 持久化 AI 流事件、版本化引申问题/运行/工具失败与兼容旧错误，隔离损坏、未知错误码或过期的恢复数据。
- `ai-chat-event.test.ts`：合法增量、版本化引申问题/运行/工具错误、旧错误、未知工具数据保留与损坏事件拒绝测试。
- `ai-chat-chunk-coalescer.ts`：在 SQLite 持久化与 IPC 广播前按原始顺序合并同一正文、推理或工具参数增量，以字符上限和最大等待时间共同限制吞吐与显示延迟，并对旧运行生成不改写数据库的临时合并回放。
- `ai-chat-chunk-coalescer.test.ts`：验证字符/延迟双阈值刷新、终止前尾部刷新、异步发出串行化、跨类型/ID/工具调用顺序，以及历史回放临时序号连续性。
- `agent-run-event-ledger.ts`：入库前归约化 run/turn/tool chunk，保证单工具终态、暂停语义、截断/取消收口与 terminal 后无迟到事件。
- `agent-run-event-ledger.test.ts`：验证未完工具参数未执行、结果唯一性、等待用户/审批暂停、Abort 收口和 terminal 后迟到 chunk 丢弃。
- `task-run-inspection.ts`：把持久化 RunPolicy、含压缩 marker 的 ContextManifest、模型、文件/Web/MCP、turn/tool/terminal 事件、Token/缓存、耗时与失败投影为脱敏 Progress、Execution Context 和诊断。
- `task-run-inspection.test.ts`：验证安全文件/Web/MCP 引用、query/输入不泄露、完成/等待 Progress、同一工具去重、生命周期、Token/执行指标、ContextManifest、失败归因与损坏事件降级。
- `task-run-recovery.ts`：应用重启时把遗留的 running 运行原子收口为带类型化可见失败的 interrupted 状态，且识别尚未写入助手消息的最新终态事件，不重放磁盘写入。
- `task-run-recovery.test.ts`：验证遗留运行和任务会话一致收口、等待输入保留、可重试中断错误，以及完成事件在消息缺失时只重放一次。
- `unified-agent-runtime.e2e.test.ts`：旧统一运行时领域链路的兼容验收；P2 后新运行的轻量工具闭环由文件/Web/Agent 分层测试负责。
- `ipc-contract.ts`：从共享频道契约反向推导参数和返回值的主进程 IPC 注册适配器。
- `ai-service.ts`：SQLite 配置仓储、Electron safeStorage，以及按实际连接、用户 turn、持久化模型事实和创作方式解析受信任 RunPolicy 与上下文上限的主进程适配。
- `mcp-service.ts`：MCP 环境/请求头前置与历史复核、加密配置、stdio/HTTP/SSE 连接池、工具发现/过滤、输出限制与 Agent 工具适配。
- `mcp-service.test.ts`：信任校验、秘密字段边界与隔离/脱敏、连接释放、逐工具禁用和运行期复核测试。
- `user-skill-service.ts`：用户 Skill 目录受限递归发现、短时扫描会话、重复/冲突识别、单个与批量原子托管导入、SQLite 目录、启停/废纸篓删除、可用性复核和正文按需加载。
- `user-skill-service.test.ts`：托管副本、扫描预览/批量安装、重复识别、附属文件保留、停用阻断、数据库 ID/文件损坏检测、符号链接拒绝和废纸篓边界测试。
- `task-service.ts`：统一任务会话校验、等待输入状态、必需/可选读取、当前 Space 活动/归档稳定分页、列表/恢复/幂等保存/重命名/置顶/归档/删除；相同消息快照不刷新最近活动时间，并继续校验兼容 mode/归属、版本化引申问题、本地消息反馈、旧错误/版本化运行与工具失败 Part、供应商原生工具标记和逐轮 Skill。
- `task-service.test.ts`：独立任务、分页边界/总数、相同快照活动时间、本地反馈往返、兼容工作区创建约束、离开工作区继续同一任务、mode 不可变、Skill 逐轮切换及任务管理测试。
- `read-only-agent-tools.ts`：工作区 Markdown 有界分页与超长单行 UTF-8 续读，以及文件核心复用的路径、版本、内容哈希和提交前复核原子写原语。
- `read-only-agent-tools.test.ts`：目录穿越、绝对路径、符号链接逃逸、文件体积、分页/单行续读、底层提交版本复核和取消测试。
- `workspace-agent-tools.ts`：新运行使用的 read/edit/write/bash 四核心、同版本完整读取许可、精确多段编辑、ExecutionEnvironment 委派与提交/命令文件观察器。
- `workspace-agent-tools.test.ts`：分页/单行完整读取许可、精确编辑、BOM/换行保留、版本/创建冲突、并发、取消、Bash 级别与观察器回归测试。
- `workspace-execution-environment.ts`：macOS Seatbelt 能力探针、最小环境、工作区只读/读写、前台进程组、输出预算和真实文件事件实现。
- `workspace-execution-environment.test.ts`：通用前台进程收口，以及 opt-in 真实 Seatbelt 越界、网络、Secret、`ls/rg/find` 和文件事件测试。
- `workspace-file-mutation-queue.ts`：按主进程解析后文件路径串行版本复核与原子写入的进程内变更队列。
- `workspace-file-mutation-queue.test.ts`：同文件串行、异文件并行与队列释放的确定性回归测试。
- `workspace-file-service.ts`：工作区真实路径与可见目录策略、Markdown 文档/目录列表、读取、创建、重命名和带版本检查的原子保存。
- `workspace-file-service.test.ts`：共享文件策略、目录穿越、符号链接逃逸、成员操作与保存冲突测试。
- `research-service.ts`：历史研究数据维护与 UI 读取兼容；保留受限 Reader、正文提取、既有计划/证据/推荐/笔记与来源材料逻辑，但不再注入新 Agent。
- `research-run-audit.ts`：只读核对单轮或带 provenance 续跑链的事件顺序、计划门禁、检索/深读/证据/推荐/最终报告与数据库/任务状态一致性。
- `research-run-audit.test.ts`：黄金运行、继承计划的续跑审计通过，以及任务状态漂移与缺失最终报告失败的确定性回归测试。
- `browser-research-reader.ts`：按本轮冻结的系统代理/直连模式执行静态读取和同分区隐藏沙箱浏览器回退，并限制子资源、复核导航公网地址。
- `research-network-settings.ts`：持久化并验证研究网页的 `system` / `direct` 模式，缺省和损坏值回退到系统代理。
- `research-network-settings.test.ts`：验证默认模式、直连持久化与损坏配置回退。
- `research-service.test.ts`：SSRF、正文/元数据提取、无关壳页识别、读取失败、证据逐字校验、交叉核验、推荐门禁、笔记/材料/写作交接与诚实部分完成回归测试。
- `research-source-save-service.ts`：只在用户明确选择推荐来源后幂等创建必要证据片段 Markdown Artifact，并关联保存状态。
- `research-source-save-service.test.ts`：用真实临时内容库验证选择前不写入、选择后创建材料，以及重复请求复用同一 Artifact。
- `agent-change-service.ts`：旧工作区写审批的只读兼容边界；保留 Diff 预览与历史决定审计，批准后进入明确失败终态且不再写盘。
- `agent-change-service.test.ts`：旧提案预览、领域审批隔离、拒绝审计、批准失效、输入防篡改与磁盘不变回归测试。
