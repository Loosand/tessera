# main

## 地位

Electron 主进程入口，持有窗口生命周期与平台能力。

## 逻辑

启动时打开本地数据库、组装 AI 配置/任务会话/可信研究/混合内容库/Agent 变更/MCP/用户 Skill 服务与 Electron `safeStorage`、注册 IPC 并创建安全窗口；托管内容库只在用户选择的目录内建立可见的“未归档”和项目目录，Markdown 正文留在文件系统，SQLite 只保存稳定引用、Artifact、资源关系和项目操作审计；显式研究在主进程创建绑定 task_run 的领域状态，以固定公网地址的受限 Reader 读取公开 HTML/纯文本，只把必要元数据、内容哈希和证据片段写入 SQLite，正文仅进入当前模型工具结果；开发环境同时全局注册 AI SDK 官方 Telemetry，Viewer 只在设置页请求时按需启动并由主进程清理；用户 Skill 经系统目录选择器进入受限单目录导入，或递归扫描后以短时会话预览并批量复制到应用托管目录；每轮运行根据当前用户文本、眼下授权资源和持久化模型事实生成受信任 RunPolicy，并按实际 Skill 复核 `SKILL.md`：所有任务都进入共用动态配置的 AI SDK `ToolLoopAgent`，当前打开工作区存在时额外注入受限 Markdown 工具，内容库工具与已启用、逐次审批的 MCP 工具按各自授权注入，历史 Chat/Agent 字段不再决定本轮能力；客户端问答结束当前模型请求并由任务会话持久化等待状态，写工具先冻结候选内容并等待 AI SDK 人工审批，再复核磁盘版本并原子落盘；生成运行由主进程持有，把本轮完整 RunPolicy、不含正文/绝对路径的资源摘要、有序事件，以及 SDK 生命周期提供的完成原因、Token/缓存和性能指标同步到 SQLite 检查点，页面离开或应用重启后通过恢复 IPC 重放；模型流启动前的同步初始化失败也必须立即结束 run 并释放内存占用，不能留下僵尸运行；任务重命名/删除与最近工作区操作由主进程确认并执行；工作区文件与目录操作在主进程验证真实路径后执行；关闭前等待渲染层确认最新草稿已经落盘。

## 约束

- 窗口保持 `contextIsolation` 与沙箱开启，禁止 Node.js 集成。
- 新增 IPC 前先在 `@tessera/contracts` 定义契约。
- AI API Key 不得记录或进入渲染层持久化存储；数据库只保存 `safeStorage` 密文，系统安全存储不可用时拒绝保存明文。
- MCP 环境变量和请求头遵守相同秘密边界；连接/启用前必须显式信任，已启用工具仍须逐次人工批准。
- 用户 Skill 只能通过系统目录选择器导入或扫描；扫描结果只返回相对路径并由短时主进程会话绑定源目录，必须限制深度/目录数/候选数，导入时仍须拒绝符号链接/特殊文件并限制文件数量和体积；运行时只读取托管 `SKILL.md`，不执行脚本或扩大权限。
- 文件路径必须在主进程中解析并限制在当前工作区内。
- 文件与目录的重命名、废纸篓、Finder 定位和路径复制只能接收已验证的工作区相对路径。
- 文档保存必须校验磁盘版本并在同目录内原子替换。
- 文档重命名必须校验文件名、保留 Markdown 扩展名并禁止覆盖已有文件。
- 每个工作区监听器随对应窗口销毁，禁止遗留后台观察器。
- 路由或组件卸载不得隐式取消生成；只有用户显式停止、任务删除、窗口销毁或应用退出可以中止主进程运行。
- 已完成运行的内存事件日志只用于短时页面恢复，必须设定释放时机与最长保留期，不替代任务消息持久化。
- 窗口关闭与应用退出必须经过请求、保存确认或取消握手，数据库只在最终退出阶段关闭。

## 成员清单

- `content-library-service.ts`：探索期托管内容库、未归档、项目、Artifact 与安全移动的混合内容领域边界。
- `content-library-service.test.ts`：内容创建、项目创建、移动回滚、授权撤销，以及普通对话进入写作和内容操作后关闭/重开 SQLite 的完整恢复回归测试。
- `index.ts`：主进程启动、窗口配置、AI 后台运行/有序事件重放与 IPC 注册。
- `ai-devtools.ts`：仅开发环境注册 AI SDK 官方 Telemetry，按需启动/探测本地 Viewer 并在退出时清理子进程。
- `ai-chat-event.ts`：校验 SQLite 持久化 AI 流事件的字段和可辨识联合，隔离损坏或过期的恢复数据。
- `ai-chat-event.test.ts`：合法增量、未知工具数据保留与损坏事件拒绝测试。
- `ipc-contract.ts`：从共享频道契约反向推导参数和返回值的主进程 IPC 注册适配器。
- `ai-service.ts`：SQLite 配置仓储、Electron safeStorage，以及按实际连接、用户 turn、持久化模型事实和创作方式解析受信任 RunPolicy 的主进程适配。
- `mcp-service.ts`：MCP 加密配置、stdio/HTTP/SSE 连接池、工具发现/过滤、输出限制与 Agent 工具适配。
- `mcp-service.test.ts`：信任校验、秘密隔离/脱敏、连接释放、逐工具禁用与运行期复核测试。
- `user-skill-service.ts`：用户 Skill 目录受限递归发现、短时扫描会话、重复/冲突识别、单个与批量原子托管导入、SQLite 目录、启停/废纸篓删除、可用性复核和正文按需加载。
- `user-skill-service.test.ts`：托管副本、扫描预览/批量安装、重复识别、附属文件保留、停用阻断、损坏检测、符号链接拒绝和废纸篓边界测试。
- `task-service.ts`：统一任务会话校验、等待输入状态、必需/可选读取、列表/恢复/保存/重命名/删除，以及兼容 mode/归属和逐轮 Skill 校验。
- `task-service.test.ts`：独立任务、兼容工作区创建约束、离开工作区继续同一任务、mode 不可变、Skill 逐轮切换及任务管理测试。
- `read-only-agent-tools.ts`：Agent 的 Markdown 列表、读取、检索、当前文档，以及可写流程复用的路径、版本、内容哈希和原子写安全原语。
- `read-only-agent-tools.test.ts`：目录穿越、绝对路径、符号链接逃逸、文件体积、搜索截断和取消测试。
- `research-service.ts`：受限公网 Reader、正文提取、研究计划/来源/证据持久化、真实进度与完整/部分完成门槛。
- `research-service.test.ts`：SSRF、正文/元数据提取、读取失败、证据逐字校验、交叉核验门槛与预算耗尽回归测试。
- `agent-change-service.ts`：工作区写工具候选内容冻结、本领域审批对账、Diff 预览、磁盘版本复核、原子写入和审计；不消费内容库或 MCP 的标准审批。
- `agent-change-service.test.ts`：批准后写入、领域审批隔离、拒绝不写入、候选冻结和外部版本冲突测试。
