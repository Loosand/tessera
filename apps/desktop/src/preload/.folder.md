# preload

## 地位

Electron 主进程与沙箱渲染层之间的安全桥。

## 逻辑

将共享 `DesktopApi` 契约映射为只读的 `window.tessera` 接口，包括应用信息、默认空间切换与作用域任务列表/分页、研究网络模式读写、研究笔记读取与推荐来源保存、开发期 AI SDK 日志入口、AI 配置读写/删除/变更订阅、模型发现、MCP 服务器管理/检测、用户 Skill 列表/系统选择器单目录导入/批量扫描安装/启停/删除、对话事件与后台运行恢复、脱敏单次运行解释、Agent 变更预览、托管内容库与 Artifact 查询、任务读取/保存/重命名/删除、最近工作区操作、窗口关闭握手，以及工作区内受限的文档和目录操作。

## 约束

- 不暴露原始 `ipcRenderer`、Node.js 对象或任意频道调用。
- 暴露值保持冻结，接口保持最小。

## 成员清单

- `index.ts`：上下文桥实现。
- `ipc-contract.ts`：从共享频道契约反向推导调用、发送与订阅签名的预加载适配器。

## 触发器

桌面 API、桥接方式、安全边界或成员文件变化时更新本文。
