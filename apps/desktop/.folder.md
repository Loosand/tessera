# desktop

## 地位

Tessera 的 Electron 桌面应用包。

## 逻辑

主进程持有平台能力，预加载层暴露窄接口，React 渲染层通过类型化 IPC 使用核心能力，并从 Skill 注册表读取无副作用的选择器元数据；开发脚本同时监听 main/preload，IPC 契约变化会重启 Electron，避免新渲染层连接旧主进程。

## 约束

- 渲染层不得直接访问 Node.js、文件系统或数据库。
- Electron 主进程使用内置 Node.js 运行时；Bun 负责开发工具与按需独立进程。
- 主进程与预加载源码的类型检查拒绝未使用的局部声明和参数，避免平台边界遗留失效代码。

## 成员清单

- `src/`：主进程、预加载和渲染层源码。
- `benchmarks/`：可版本化的编辑器性能预算。
- `build/`：Tessera 品牌图标与 macOS 内部/正式签名共用的最小权限声明。
- `scripts/`：在独立 Electron 进程运行的验证 runner。
- `electron.vite.config.ts`：Electron Vite 构建配置；主进程只保留 Electron、Node 内建模块和 SQLite 原生模块为外部依赖。
- `electron-builder.yml`：macOS DMG/ZIP 发行产物、应用标识、ASAR、Developer ID 签名与 Apple 公证边界配置。
- `package.json`：桌面应用依赖和脚本，包括会重启 main/preload 的 Electron Vite watch、TipTap、CodeMirror 6，以及分离的内部/正式 Electron Builder 发行命令。
- `tsconfig*.json`：各运行时 TypeScript 配置。

## 触发器

进程边界、构建入口、运行时依赖或桌面脚本变化时更新本文。
