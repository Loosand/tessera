# build

## 地位

Electron Builder 使用的桌面发行资源目录。

## 逻辑

`icon.png` 保存可继续迭代的 1024px 品牌主稿，`icon.icns` 是 macOS 打包输入；权限声明由主应用和继承进程共同使用。

## 约束

- 图标主稿必须保留 Alpha 通道，并在 16px 到 1024px 下保持可辨识。
- 正式发行只能使用仓库内显式版本化的 `icon.icns`，不得回退到 Electron 默认图标。
- 权限声明保持最小化；新增 entitlement 必须说明对应的平台能力和安全边界。

## 成员清单

- `icon.png`：Tessera macOS 应用图标的 1024px PNG 主稿。
- `icon.icns`：由主稿生成的 macOS 多尺寸图标容器。
- `entitlements.mac.plist`：主应用与继承进程共用的 Hardened Runtime 权限声明。

## 触发器

品牌图标、macOS 打包资源或 entitlement 变化时更新本文。
