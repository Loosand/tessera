# scripts

## 地位

桌面包的独立开发与验证 runner。

## 逻辑

脚本在产品运行时之外启动专用进程，读取构建产物并把验证结果写入仓库忽略的 artifacts 目录。

## 约束

- runner 不得复用用户工作区、数据库或正常应用窗口。
- 性能脚本必须设置超时并在异常后退出 Electron。
- 生成报告不得进入源码目录或默认纳入版本控制。

## 成员清单

- `editor-benchmark.mjs`：启动隔离 BrowserWindow、收集编辑器结果、评估预算并写入报告。
- `package.json`：声明独立 Electron runner 入口，防止 CLI 回退到桌面产品主进程。

## 触发器

脚本成员、运行方式、输出目录或进程权限变化时更新本文。
